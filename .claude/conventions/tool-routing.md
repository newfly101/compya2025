# 도구 라우팅 룰 (어떤 요청에 무엇을 쓰나)

> 비슷한 도구가 같은 요청에 동시에 반응하는 것을 막는다. 표는 **위에서부터 읽고 처음 걸리는 줄에서 멈춘다.**

---

## 1. 다섯 갈래 — 고르는 순서

위에서부터 읽고 **걸리는 곳에서 멈춘다.** 아래로 갈수록 비용이 크다 — 컨벤션 문서는 대화에 부담이 없지만, MCP·플러그인은 **쓰지 않는 대화에서도** 이름과 설명이 실린다.

| 순서 | 갈래 | 이럴 때 | 예시 |
|---|---|---|---|
| 1 | **컨벤션 문서** | 규칙만 적어두면 될 때 | `docs/convention/frontend.md`, `.claude/conventions/responsive-mobile-first.md` |
| 2 | **스킬** | 규칙에 더해 "이럴 땐 이렇게" 절차가 필요할 때 | `impeccable`, `archify` |
| 3 | **에이전트** | 파일을 여러 개 고치거나 병렬로 돌릴 때 | `frontend-developer`, `planner-division` |
| 4 | **MCP (바깥 연결)** | 저장소 밖 데이터가 필요할 때 | Figma 커넥터, Notion |
| 5 | **플러그인** | 위 넷이 남이 만든 묶음으로 이미 있을 때 | Ponytail |

---

## 2. 라우팅 표 — 요청별 단일 정답

| 요청이 이런 것이면 | 이걸 쓴다 | 상태 |
|---|---|---|
| 이 프로젝트의 **도메인 화면** 작업 — 기획서가 있고 Figma 에 반영해야 함 | **프로젝트 파이프라인** (`designer-render` / `designer-review` 에이전트) | 사용 가능 · **이 줄이 다른 모든 줄을 이긴다** |
| 참고할 **실제 서비스 화면**을 찾아달라 | **Inspo** | 사용 가능 · 디자인 레퍼런스는 이거 하나만 켠다 |
| 이미 있는 화면을 다듬는다 — 여백·정렬·색·타이포·접근성·빈 화면 처리 | **impeccable** | 사용 가능 |
| 새 화면을 처음부터 만든다 — 랜딩·포트폴리오·전면 리디자인 | **design-taste-frontend** | 사용 가능 |
| 고르는 게 목적 — 색 조합 / 폰트 짝 / 스타일 / 차트 종류 | **ui-ux-pro-max** | 사용 가능 |
| **움직임**이 주제 — 전환·등장·마이크로 인터랙션 감사 및 개선 | **emil-design-eng** | 사용 가능 (꺼져 있으면 `ui-ux-pro-max` 의 모션 프리셋으로 대체) |
| 그림인데 **숫자가 주인공** — 추이·비중·지표 | **dataviz** | 사용 가능 |
| 그림인데 숫자가 없고, 결과물이 **공유 웹페이지(아티팩트)** | **artifact-diagramming** | 사용 가능 |
| 그림인데 숫자가 없고, 결과물이 **독립 파일 한 장** — 구조도·흐름도·순서도 | **archify** | 사용 가능 |
| 브라우저인데 **로그인이 걸린** 실제 사이트를 눈으로 확인 | **claude-in-chrome** | 사용 가능 |
| 브라우저인데 **매번 같아야 하는** 반복 검사·화면 캡처 자동 수집 | **Playwright** | 사용 가능 |
| **도메인 단위 코드 리뷰** — 포트폴리오 문서 산출까지 목적 | **`/code-review-doc`** | 사용 가능 · `/code-review`(현재 diff·PR 단위 빠른 점검)·`ponytail-audit`(과설계·삭제 대상 탐색)과 목적 분리 |

---

## 3. 충돌이 나면 이 세 줄로 가른다

- 도메인 화면 작업이면 **무조건** 프로젝트 파이프라인이 이긴다. 범용 스킬이 먼저 나서면 안 된다
- 그림 세 갈래 — **숫자가 있으면 `dataviz`.** 없으면 "어디에 넣을 그림인가" 로 나머지 둘을 가른다 (아티팩트 안 → `artifact-diagramming`, 독립 파일 → `archify`)
- 브라우저 두 갈래 — **로그인이 필요하면 `claude-in-chrome`, 반복 재현이 필요하면 Playwright.** 한 작업에 둘을 같이 쓰지 않는다

---

## 4. 자가 점검

- [ ] 표를 위에서부터 읽었고, 처음 걸린 줄에서 멈췄다
- [ ] 같은 요청에 도구를 두 개 이상 켜지 않았다
- [ ] 미설치 도구가 걸렸다면 대체 수단을 쓰고, 그 사실을 보고에 남겼다
- [ ] 도구를 새로 붙이거나 끄면 이 표를 같이 고쳤다
