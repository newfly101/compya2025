# HITL 마커 시스템

> planner / designer / 기타 agent 공용. 의사결정 항목에 마커 일관 적용.

---

## 1. 3종 마커

| 마커 | 의미 | 처리 |
|---|---|---|
| 🟨 **가정** | 합리적 default. 사용자 수정 가능 | 자동 진행 OK |
| ❓ **미정** | 결정 필요. 답변 후 확정 | 자동 진행 OK + § 끝 집계 |
| 🔴 **위험** | 강제 HITL 분야 | 사용자 답변 전 확정 X |

---

## 2. 강제 HITL 분야 (agent 별)

### planner (기획)

| 분야 | 예시 |
|---|---|
| 법무 | 개인정보 / 약관 / KISA / GDPR / PCI-DSS / 전자상거래법 |
| 결제 | PG 연동 / 환불 / 정산 / 가격 정책 |
| 권한 | 인증 / 권한 등급 / SecurityConfig / SSO |
| DB 파괴적 | DROP / DELETE / 마이그레이션 / 컬럼 제거 |

### designer (디자인)

| 분야 | 예시 |
|---|---|
| 디자인 토큰 파괴적 변경 | 기존 color/typography/spacing/radius 토큰 값 **변경** (추가는 일반 완화) |
| 컴포넌트 라이브러리 구조 변경 | variant 제거 / props 시그니처 변경 / 컴포넌트 삭제 |
| 외부 자산 도입 | 라이선스 불명 이미지/아이콘/폰트/illustration/외부 컴포넌트 라이브러리 |

---

## 3. 사용 규칙

1. 🔴 항목은 산출물에 **가정값만 기재 + 마커**. 확정값 X
2. 🟨 / ❓ 항목은 자동 진행 OK + 산출물 끝 § "사용자 확인 필요 항목" 에 일괄 집계
3. 사용자 답변 받기 전엔 🔴 항목 코드/Figma 적용 X (산출물 plan 단계까지만)
4. 답변 수신 시 마커 제거 + 확정값 대체
