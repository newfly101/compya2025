## 2. 모바일 우선 · 320 보호

- 단일 코드베이스, 단일 컴포넌트. SSR/CSR 분기 X, 컴포넌트 분기 X, multi-column X, hover 의존 X, data table X(card list), sidebar X(Drawer)
- 320~480 사이는 `clamp() / min() / max()` · % 로 fluid. **media query 는 320px 미만 폴드폰 보호만** 허용
  ```css
  .page-wrapper { max-width: 480px; margin: 0 auto; width: 100%; }
  @media (max-width: 320px) { .component { font-size: .75rem; } }   /* 유일한 예외 */
  ```
- `width: 480px` 고정 금지 → "최대 폭 + 100%". 가로 스크롤 금지. 이미지·영상 `max-width: 100%`. 긴 단어·URL 줄바꿈, 한글은 단어 단위. 줄바꿈 금지 속성 X
- `box-sizing: border-box` 전역. `border` 는 내용 영역을 줄인다 → 고정 크기 자리는 `outline`
- Figma frame 도 480 하나. 375/390/414 별도 frame X

## 3. px 를 어디에 쓰나

| 영역 | px 직접 |
|---|---|
| 화면(도메인) 코드 · 공용 부품 | 금지. 예외: `1px` 테두리, `0.5px` 얇은 선, `100%` |
| 토큰 정의 파일 (`global/styles/**`) | 허용 — 원본 값은 여기서 px |

글자 크기는 네 경로(px · rem · `rem()`/`font-size-rem()` · `$font-size-*`)로 들어온다. 어느 경로든 위 아홉 값 밖은 위반 — grep 은 `fe-design-audit.md` § 2.

## 4. 색 3축

```
원색 값 (직접 참조 금지) → 의미 이름 (배경/글자/브랜드/테두리/상태/분류/등급) → 화면 코드는 의미 이름만
```

| 축 | 용도 | 팔레트 |
|---|---|---|
| 상태 | 성공·위험·주의 (초록·빨강·노랑, 각 옅은 배경 버전) | 상태 전용. 신규·등급 표시에 재사용 금지. 글자·테두리·아이콘으로만 |
| 분류 | 신규·BETA 등 종류 표시 | `--color-cat-new` `-route` `-mark` `-neutral` 4색, 상한 5. 색 외 신호(테두리·굵기·아이콘·위치) 병행 |
| 등급 | 구종·카드·스킬 등급 (순서 척도) | 게임 본편 등급 색 그대로, 분류 5색 상한에 불포함. **값 미정** — 본편 체계 확보 후 |

- **빨강은 분류에서 `NEW` 만.** 분류 빨강 = 불투명 배지 채움, 상태 빨강 = 글자·테두리·아이콘. 형태로 갈린다
- `HOT`(인기) 분류는 폐기 — 색 배정 없음 (코드 제거 별도)
- 새 색은 원색 정의 + 의미 이름 두 단계 모두 추가
- 리터럴이 정답인 자리: 테마에 따라 바뀌지 않는 면 위 — 브랜드 고정색(네이버·카카오·브랜드 보라) 위 흰 글자, 선수 사진과 그라데이션, 인게임 색 위 글자, 불투명 배지 채움 위 글자. 근거 주석 필수

## 5. 대비

- 본문 **4.5:1**, 큰 글자(굵은 18.66px↑ 또는 24px↑)·UI 부품 **3:1**
- **두 테마 모두 계산.** 밝은톤 통과·다크 미달 사례 11곳 있었음 (흰 글자 on `--color-brand` = 3.51:1)
- 반투명 채움 위 글자는 **합성 배경** 기준 (`.18×전경 + .82×배경`). 채움을 어둡게 하면 채움이 부모 면에서 안 보일 수 있다 — 양쪽 같이
- `L = 0.2126R + 0.7152G + 0.0722B` (감마 보정 채널) · `contrast = (L_light + 0.05) / (L_dark + 0.05)`

## 6. 화면 골격 · 부품

- 상단바 + 서랍 + 스크롤 본문 = `<MobileLayout>` 하나. 도메인 헤더 금지. 상단바 설정은 `fe-convention.md` § 5
- 인터랙션: 터치 우선, 스와이프·pull-to-refresh·long-press 권장, modal/drawer/sheet 위주
- 이미 있는 부품: 뱃지 3종(`fe-badges.md`) · 섹션 틀 · 스위치 · 알림 모달(용도 고정). 없는 부품(버튼·입력·범용 모달·시트)은 화면마다 만들지 말고 `global/ui/` 공용화 검토
