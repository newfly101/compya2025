# policy — 변경 이력

- 버전: 유지 (커밋 없음)
- 커밋: (없음 — policy 도메인 폴더를 건드린 커밋 0건)

**고친 것**

policy(개인정보처리방침·이용약관·소개·문의 4개 정적 화면, `web/src/domains/policy/**`)는 이번 리뷰 라운드에서 코드를 한 줄도 고치지 않았다. 발견 2건 중 하나는 심각도가 낮고 요구사항 자체가 불명확해 보류, 다른 하나는 법무 판단이 먼저 필요한 사안이다.

**손대지 말 것**

- `PrivacyPolicyScreen.jsx`·`TermsScreen.jsx`의 법률 문구는 법무 판단 전에 임의로 완화하지 말 것.
- `EFFECTIVE_DATE`/`AMENDED_DATE`가 고정 문자열인 것 — 개정 최소 7일 전 고지 규칙에 맞춰 미리 역산해 둔 값이다. `new Date()` 같은 동적 계산으로 바꾸면 시행일이 매번 달라지는 회귀가 생긴다.
- `ANALYTICS_ENABLED = false`(정상 상태) — "수집 안 되는 버그"로 오인해 켜지 말 것.
- `ContactScreen.jsx`의 오픈채팅·이메일 문의 분리 안내 구조는 정상이다 — 하나로 합치지 말 것.

**미결**

- 개인정보처리방침이 "탈퇴일로부터 1개월 보관 후 파기"라고 안내하지만 실제로는 그 배치가 저장소 어디에도 없다(`@Scheduled` 검색 0건) — 법무·기획 미결. 파기 방식(행 삭제 vs 개인정보 칸만 비우기) 자체가 계정 PRD에서 이미 "보류"로 명시돼 있다. `users` 도메인 이력에도 같은 문제가 코드 관점으로 기록돼 있다.
- 소개 화면(`AboutScreen.jsx`)의 "제공 기능" 목록에 가이드·마일리지·스킬 백과사전 3개가 빠져 있다 — "모든 기능을 다 나열해야 한다"는 확정 규칙이 없어 결함으로 확정하지 않음. 운영자가 방향을 정하면 3줄 이내로 반영 가능.
