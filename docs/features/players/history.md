**손대지 말 것**

## 2026-09-28 — 카드 종류 필터에서 시그니처 카드가 "일반"에서 빠지던 문제

- 버전: 1.0.1 (patch)
- 커밋: `ded2f269`

**고친 것**

- 선수 백과사전 필터에서 카드 종류 "일반"만 선택하면 시그니처를 겸하는 카드가 결과에서 사라지던 버그를 고쳤다. `adapter.js`가 `kinds: [sg ? KIND_SIGNATURE : KIND_NORMAL]`처럼 둘 중 하나만 배타적으로 고르던 것을, 설계 원본 데이터(콤마로 여러 값 나열, 시그니처 카드는 항상 "일반"도 포함)에 맞춰 `kinds: sg ? [KIND_NORMAL, KIND_SIGNATURE] : [KIND_NORMAL]`로 바꿨다. 필터링 쪽에 특례를 넣는 대신 값을 만드는 지점 한 곳만 고쳐, 카드 종류가 늘어도 특례가 계속 붙지 않게 했다.

**손대지 말 것**

- 카드 종류 필터 UI(시그니처/일반 탭 구조) 자체는 게임 내 카드 등급 체계를 그대로 반영한 정상 설계다 — 이번에 고친 것은 값을 만드는 로직 한 줄이지 필터 기능 자체가 아니다.
- `loaded` 재요청 차단(`thunks.js` condition 가드)은 카드 11,668건 규모에서 의도된 보호다 — historyLegend처럼 매번 재요청으로 바꾸면 오히려 성능이 나빠진다.
- `PLAYERS_TABLE`/`PLAYERS_LIST`의 광고 자리(두 번째 구간부터 노출)는 과거 반려 대응으로 넣은 의도된 가드다.
- 선수 백과사전 리스트형(표) 보기의 구단·연도 열, 도움말, 정렬 기능은 전부 구현이 끝난 상태다 — 미완으로 보고 다시 작업하지 말 것.

**미결**

- `has_signature=1`인 카드가 실제 몇 건이었는지는 DB 접속 금지로 세어보지 못함(코드 수정 자체는 완료) — 필요하면 DB 접근 권한이 있는 세션에서 실측.
- 캐시 만료 시간(TTL) 없음 — 운영 설정(`spring.cache.type`) 변경은 별도 승인 사안.
