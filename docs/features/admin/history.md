# admin — 변경 이력

> `admin` 은 운영자 전용 셸(`/admin/:tab`) 자체를 가리킨다. 쿠폰·이벤트·공지 등 개별 기능의 "관리자 화면"은 각 기능 이력에 있다.

## 2026-09-30 — 통계 탭 자가 테스트 반영: 세로 나열·시간대별 목록·경로/제목 토글·바로가기·기간 3버튼·전 카드 기간 통일·증감 비교 (FE)

- 버전: 1.5.0 (minor)
- 커밋: `b1aa5840`(web)

**고친 것**

- 가로로 넘겨 보던 카드 5개(개요·상위 경로·추이·방문자 구성·외부 유입)를 세로로 쭉 나열하는 방식으로 바꿨다.
- 시간대별(0~23시) 방문 분포를 가로 막대 그래프 대신, 시각·방문자·페이지뷰 숫자를 같이 보여주는 24행 목록으로 바꿨다. 활동이 없던 시각도 0건으로 표시한다.
- 상위 경로 표에 "경로 | 제목" 토글을 추가했다 — 페이지 주소 대신 화면 제목으로도 볼 수 있다.
- 화면 맨 위에 카드 5개로 바로 이동하는 버튼 줄을 추가했다.
- 조회 기간 선택을 오늘·7일·30일·기간 4개 버튼에서 오늘·특정 일자·기간 3개로 바꿨다. "특정 일자"는 어제를 기본값으로 골라 즉시 조회되고, "기간"은 시작·종료일 직접 입력과 "7일"·"30일" 빠른 선택(둘 다 어제까지 기준)을 같이 뒀다.
- 카드 5개가 전부 이 하나의 기간 선택을 그대로 따르게 통일했다(추이 카드가 따로 갖고 있던 날짜 범위를 없앴다) — 각 카드 제목 옆에 지금 적용된 기간을 작게 표시한다.
- 추이 카드의 막대가 어떤 지표를 나타내는지 범례로 밝혔다(일별은 순방문자, 시간대별은 페이지뷰 기준).
- 선택한 기간과 바로 직전의 같은 길이 기간을 비교하는 기능을 추가했다 — 개요 카드 숫자마다(순방문자·페이지뷰·이벤트별 건수·세션당 페이지뷰) 증감률 배지(▲/▼/-)를 붙였고, 일별 추이 그래프에는 직전 구간을 옅은 색으로 겹쳐 그린다. 비교 대상 구간이 서비스 시작일(2026-01-29)보다 이르거나 서버가 거부하면 배지는 "-"로, 그래프는 조용히 겹쳐 그리지 않는다.

**손대지 말 것**

- 직전 구간 비교는 새 API 를 만들지 않고 기존 요약·추이 조회를 구간만 바꿔 한 번 더 호출한다(요청이 두 배가 된다) — 어드민 전용 화면이라 감수한 것, 공개 화면에는 이 패턴을 옮기지 않는다.
- 상위 경로 "제목" 표시는 페이지 주소를 라우트 설정과 대조해 추론한 값이다. 공지·가이드처럼 주소만으로 실제 글 제목을 알 수 없는 경우 대표 제목("공지사항 상세" 등)으로 대신 보여준다 — 실제 글 제목이 아니다.
- 카드 폭을 320px 로 고정해 다음 카드가 살짝 보이게 했던 이전 항목의 "디자인 검토 전 임시값" 메모는, 이번에 가로 스크롤 자체를 없애며 해소됐다.
- 이번 화면이 쓰는 응답 필드는 BE 새 테이블이 실제 데이터베이스에 반영되기 전까지는 호출 시 오류가 난다(아래 BE 항목 참고) — 반영은 사용자가 별도로 진행한다.

**미결**

- 없음.

## 2026-09-30 — 통계 탭 방문자 정확도 개선 + 임의 기간·시간대 추이 (BE)

- 버전: 1.5.0 (minor)
- 커밋: `fb4b7ddf`(be) · `24987420`(sql)

**고친 것**

- 접속자 국가·도시를 CloudFront 헤더 대신 GeoIP 조회로 채운다 — 헤더가 애초에 안 들어오던 문제를 해결. 조회용 DB 파일이 없으면 국가/도시는 그냥 비워두고 넘어간다(파일 배치는 별도 작업).
- 쓰이지 않던 상품 식별자 컬럼을 이벤트 저장에서 뺐다 — 콘텐츠 식별자 하나로 통일.
- 상위 방문 경로 표에 순방문자 수·재방문율을 추가했다. 오늘 하루는 재방문 여부를 가늠할 수 없어 재방문율을 빈칸으로 둔다.
- 기간을 직접 골라 조회하는 기능과, 그 기간의 일별 추이를 보여주는 조회를 새로 만들었다.
- 최근 3개월 안에서 시간대별(0~23시) 방문 분포를 볼 수 있게 됐다.
- 7일·30일 조회의 방문자 수 계산 방식을 근사치에서 정확한 값으로 바꿨다.
- 오늘 하루의 세션당 페이지뷰 계산을, 매일 새벽 집계 배치가 쓰는 것과 같은 "30초 안 재방문은 하나로 본다" 방식으로 통일했다.
- 신규 방문자와 재방문자를 구분해 보여주는 값과, 가입 전환(바로 가입/재방문 후 가입) 값을 통계에 추가했다.
- 기간을 입력받는 조회(재집계·임의 기간 조회·추이 조회) 세 곳이 미래 날짜나 서비스 시작일 이전 날짜를 똑같은 방식으로 걸러내게 통일했다.
- 원본 접속 기록을 3개월만 보관하고 그 이전은 매달 자동으로 정리하는 배치를 새로 만들었다(실제 정리 대상 테이블 구조 변경은 운영 작업으로 별도 진행).
- 이번 작업이 의존하는 데이터베이스 반영용 스크립트 4건(도시 컬럼 추가, 상품 식별자 컬럼 삭제, 방문자 최초 관측 테이블 신설, 접속기록 월별 정리용 구조 변경)을 `sql/` 에 작성했다 — 실행은 사용자가 직접 판단해 진행.

**손대지 말 것**

- 이번 작업이 의존하는 새 테이블·새 컬럼(방문자 최초 관측일 테이블, 접속기록의 도시 컬럼, 상품 식별자 컬럼 제거, 접속기록 보관용 테이블 구조 변경)은 아직 실제 데이터베이스에 반영되지 않았다 — 반영 전까지는 이 기능들을 실제로 호출하면 데이터베이스 오류가 난다. 반영은 사용자가 직접 판단해 진행.
- GeoIP 조회용 DB 파일 배치·라이선스 키 발급은 이번 작업 범위 밖(사용자 작업).

## 2026-09-30 — 통계 탭 가로 스크롤 재구성 + 방문자 구성·전환·시간대별 추이 (FE)

- 이번 화면이 쓰는 새 응답 필드(순방문자·재방문율·방문자 구성·가입 전환·추이)는 BE 쪽 새 테이블이 실제 데이터베이스에 반영되기 전까지는 호출 시 오류가 난다(위 BE 항목의 "손대지 말 것" 참고) — 반영은 사용자가 별도로 진행한다.

## 2026-09-29 — 방문·이벤트 수집 품질 개선 + 통계 탭 지표 확장 (BE)
