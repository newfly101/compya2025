## 2026-09-29 — 통계 탭 7일·30일 실값 전환 + 수동 재집계 API (BE)

- 버전: 1.3.0 (minor)
- 커밋: `60aed844`(be) · `e2adb8bf`(web)

**고친 것**

- 일별 집계 배치가 기기 종류별·세션·외부 유입 상위도 함께 채운다 — 기기·세션의 페이지뷰는 같은 세션·화면을 30초 안에 다시 본 것은 중복으로 보지 않고 뺀다.
- 7일·30일 통계 조회가 더 이상 "미측정"을 반환하지 않는다 — 위 집계값을 그대로 읽어 기기 비율·세션 수·외부 유입 상위를 실값으로 준다.
- 세션당 페이지뷰를 서버가 소수 1자리로 계산해 응답에 실어준다(오늘·7일·30일 공통) — 화면은 이 값을 그대로 보여주기만 하면 된다.
- 관리자가 날짜를 골라 그 날짜의 집계를 수동으로 다시 돌릴 수 있는 기능을 추가했다(집계 실수·누락 시 재실행용, 여러 번 눌러도 안전).

**손대지 말 것**

- 신규 집계 테이블 3종(기기·세션·외부유입)은 이미 사용자가 SQL 을 실행하고 서버를 재시작한 뒤에 이 작업을 시작했다 — 이번 작업에서 DDL 파일을 만들거나 실행하지 않았다.
- 세션당 페이지뷰의 분모는 기간마다 다른 소스를 쓴다(오늘=원본 직접 집계, 7일·30일=일별 집계 합산) — 기존 방문자·페이지뷰 수치도 같은 방식이라 새로운 불일치가 아니다.
- 재집계 날짜에 미래 날짜를 넣거나 같은 날을 여러 번 돌려도 막지 않는다 — 원본에 그 날 데이터가 없으면 0건으로 채워질 뿐 오류가 아니고, 다시 돌려도 최신값으로 덮어쓸 뿐이라 별도 검증을 넣지 않았다.

## 2026-09-29 — 방문·이벤트 수집 품질 개선 + 통계 탭 지표 확장 (BE)

- 버전: 1.2.1 (patch) — 아래 (FE) 항목(1.2.0)과 같은 라운드의 서버 쪽 구현
- 커밋: `60aed844`(be) · `e2adb8bf`(web)

**고친 것**

- 이벤트를 저장하기 전에 필수값(익명 방문자·세션 식별자·화면 경로, 화면 진입 이벤트는 진입 방식까지)을 검사한다 — 형식이 이상한 이벤트만 걸러내고 나머지는 그대로 저장하며, 거부 건수는 서버 로그에만 남긴다.
- 접속 기기 정보(User-Agent)로 운영체제·브라우저·기기 종류(모바일/태블릿/PC)를 서버가 판정해 저장한다 — 화면 폭이 480px 이하면 UA 판정과 무관하게 항상 모바일로 본다.
- 콘텐츠 클릭 일별 집계에서 콘텐츠 종류가 비어 있는 값끼리 서로 덮어써 마지막 값만 남던 버그를 고쳤다.
- 검색 이벤트도 화면별 일별 집계 대상에 포함시켰다.
- 오늘 통계의 순방문자·페이지뷰·이벤트 수·인기 화면 조회가 매번 전체 데이터를 훑던 것을 인덱스를 타는 방식으로 바꿨다. 오늘의 순방문자 정의를 "화면 조회 기준"으로 통일했다(7일·30일 통계와 같은 기준).
- 오늘 기준 세션 수 · 기기 비율 · 외부 유입 상위 조회를 새로 추가했다(어드민 통계 탭이 쓴다).

**손대지 말 것**

- `item_id` 컬럼은 스키마만 두고 필수값에서 뺐다 — 실제로 값을 채워 보내는 화면이 아직 없다(다음 라운드).
- DB 컬럼 추가(`session_id` 등 7개) 초안(`sql/draft/feat/admin-internal-stats/02_event_columns.sql`)은 이번 작업에서 실행하지 않았다 — 실행은 사용자가 직접 한다. 실행 전까지는 이벤트 저장이 "컬럼 없음" 오류로 실패한다(컴파일·매퍼 문법까지만 확인됨).
- 신규 일별 집계 테이블 3종(기기·세션·referrer)은 미승인이라 만들지 않았다 — 7일·30일의 기기 비율·세션당 페이지뷰·외부 유입은 계속 "미측정"으로 응답한다.

## 2026-09-29 — 방문·이벤트 수집 품질 개선 + 통계 탭 지표 확장 (FE)

- 버전: 1.2.0 (minor)
- 커밋: `60aed844`(be) · `e2adb8bf`(web)

**고친 것**

- 방문자를 세션 단위로도 구분한다 — 브라우저 쿠키(30분 무활동 시 만료, 활동 있으면 계속 연장)로 같은 방문을 하나의 세션으로 묶는다.
- 페이지 이동 방식(새로고침/최초 진입/뒤로가기/화면 안 이동)을 구분해 같은 화면이 다시 그려질 때 방문 기록이 중복으로 쌓이던 문제를 막았다.
- 화면 폭을 함께 보내 서버가 기기 종류(모바일/태블릿/PC)·운영체제·브라우저를 판정할 수 있게 했다.
- 외부 링크 클릭·유입 경로를 저장할 때 전체 주소가 아니라 접속한 사이트(호스트)만 남긴다 — 내부 이동은 유입 기록에서 뺀다.
- 통계 탭에 기기 비율 · 세션당 페이지뷰 · 외부 유입 상위를 추가했다(오늘 기준만 실측, 7일·30일은 "미측정"으로 표시 — 뒷단 집계 테이블은 다음 라운드).
- 이벤트 건수가 있는데도 통계 탭이 "데이터 없음"으로 잘못 표시되던 문제를 고쳤다.
- 어드민 홈 카드 그리드에서 "통계" 카드가 다른 탭처럼 빈 숫자("–")를 보여주던 것을 없앴다(통계는 건수 개념이 없는 탭).
- 어드민 홈의 "오늘" 날짜를 한국 시간 기준으로 고쳤다 — 자정~오전 9시 사이 하루 밀리던 문제.

**손대지 말 것**

- 기기·화면 정보만 수집한다(개인식별 아님) — 방침 문구 변경 불필요, 이미 확인됨.
- DB 컬럼 추가(`session_id` 등 7개)는 초안만 두고 실행은 사용자가 직접 한다 — 실행 전까지 로컬 수집은 컬럼 없음 오류로 저장 단계에서 실패할 수 있다(FE/BE 코드는 실행 이후를 대비해 이미 반영).

**미결**

- 신규 일별 집계 테이블 3종(기기·세션·referrer)이 미승인 상태라 7일·30일 구간의 기기 비율·세션당 페이지뷰·외부 유입은 계속 "미측정"이다.
