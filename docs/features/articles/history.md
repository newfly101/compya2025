# articles(공략 글) — 변경 이력

> 아직 코드가 없는 기획 단계다. 공략 글에 들어갈 게임 콘텐츠 정리는 `docs/post-content/` 에 있다.

## 2026-10-17 — 공략 글 기능 첫 기획

- 버전: 0.1.0 (기획)
- 커밋: 기획 문서만 (코드 없음)

**고친 것**

- 운영자가 어드민에서 이미지와 설명이 들어간 공략 글을 쓰고 발행하는 기능의 기획서(`spec.md`)를 처음 작성했다. 목적은 구글 애드센스 심사에서 지적된 "자체 콘텐츠 부족"을 채우는 것이다.

**손대지 말 것**

- 기존 `guides` 도메인(정적 도움말 12편)은 그대로 둔다 — 공략 글은 새 도메인으로 분리하기로 사용자가 정했다.

**미결**

- 도메인 이름(`articles` 가정) · 어드민 탭 이름 · 새 테이블 4개 DDL(운영 DB 승인 필요) · 작성 권한 · 이미지 주소 허용 범위 — `spec.md` § 6 확인 필요 항목.
