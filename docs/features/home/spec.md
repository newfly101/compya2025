# home

## 1. 무엇을 하는 기능인가

이 사이트의 첫 화면이다. 비로그인 상태에서도 쿠폰·이벤트·공지·퀴즈 최신 정보를 한 번에 미리 보고, 퀵메뉴로 각 공략 도메인(레전드 재료·스킬·선수 백과·마일리지·확률공시)으로 바로 이동할 수 있다.

## 2. 화면과 진입 경로

| 화면 | 주소 | 어디서 들어오나 |
|---|---|---|
| 홈 (SC-07-01) | `/` (index) | 첫 진입 주소. 상단바 로고 클릭으로도 돌아온다 |
| 바로가기 편집 | `/home/shortcuts` | 홈 바로가기 머리의 `편집`(로그인 사용자에게만 보임). 로그인 필요(`AuthGuard`, 문서 제목 "컴프야펀 \| 바로가기 편집") |

퀴즈는 독립 라우트가 없다 — 이 화면 안 섹션으로만 존재한다(`screen-id.md` § 3).

## 5. 하지 않는 것

- 참여율 측정 이벤트(카드·바로가기 클릭 집계) — 이번엔 하지 않는다(2026-10-02)
- 바로가기 서버 저장 — 우선 브라우저 저장, 이전은 사용 패턴을 본 뒤
- "최근 편집 바로가기" — 이번 주기 일정으로 대신한다
- 홈의 유일한 광고 슬롯(쿠폰 섹션 뒤)이 쿠폰 존재 여부에 종속된 구조를 바꾸는 것 — 쿠폰이 0건이면 광고가 조용히 사라진다(`HomeScreen.jsx:84`, 유지 확정 2026-09-30, 구 H6)
- 미리보기 건수 제한을 전 섹션에 통일하는 것 — 공지만 `PREVIEW_LIMIT=3`으로 잘리고 쿠폰·이벤트는 전량 노출된다. 공지 3건 제한 유지가 확정됐다(2026-09-30)
- 홈 재방문 시 캐시 확인 없이 재요청을 보내는 것을 고치는 일 — 성능 개선 여지는 있으나 이번 라운드는 순서 문제로 다루지 않았다
- 퀵메뉴 7항목을 모두 공용 라우트 상수(`ROUTE_PATHS`)로 통일하는 것 — 일부는 문자열 리터럴로 남아 있다(`requirements.md` FR-HM-04)
- 커뮤니티 인기글/자유게시판 섹션 — `community` 도메인 동결과 함께 주석 처리돼 있다
