## 2026-09-28 — 확률 공시 안내 문구가 "로그인 필요"라고 잘못 서술돼 있었음

- 버전: 1.0.1 (patch)
- 커밋: `e40f7bb0`

**고친 것**

- 도움말과 메뉴 설정 여러 곳이 확률 공시 화면을 "로그인 후 이용 가능"이라고 안내했지만, 실제로는 로그아웃 상태에서 주소를 직접 입력하면 그대로 보였다. 문구를 실제 동작(공개)에 맞춰 고쳤다.
- 이 커밋은 여러 기능에 걸쳐 있다 — 앱 전역 메뉴 설정과 홈 화면의 퀵메뉴 파일도 함께 고쳤고, 이 문서에는 도움말(`probabilityGuide.js`) 몫만 기록한다.

**손대지 말 것**

- 확률 공시는 게임사 공시 데이터라 비로그인 공개가 맞다는 판단이 이미 내려져 있다 — 로그인 가드를 새로 넣는 방향은 채택되지 않았다.

**미결**

- `legendStatsGuide.js`에 있는 단축 URL 하나가 실제로 살아있는 링크인지 확인이 안 됐다(네트워크 접근이 막힌 환경에서 리뷰함) — 사람이 직접 열어 확인해야 한다.
- 12편 중 6편은 구조·라우팅만 확인했고 콘텐츠 문구 하나하나를 원본 자료와 대조하지는 않았다.
