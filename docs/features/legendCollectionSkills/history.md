# legendCollectionSkills — 변경 이력

## 2026-10-02 — 조회와 편집 분리 · 공용 탭 · 비로그인 안내 화면

- 버전: 1.2.0 (minor)
- 커밋: 41b42cbf

**고친 것**

- 이름을 "내 레전드 스킬 기록"(메뉴·홈 카드)으로 통일하고 상단바 제목은 "레전드 재료", 탭 라벨은 "스킬 기록"이다(REQ-LCSK-25). 상단바 아래 공용 탭 3개와 "이 페이지 활용 가이드" 아코디언을 두고, "← 내 재료 보유 현황" 링크와 부제는 없앴다(REQ-LCSK-22·26).
- 비로그인이 주소로 들어오면 홈으로 튕기지 않고 같은 주소에서 "스킬 기록은 로그인하면 쓸 수 있어요" 안내 화면(예시 카드, `로그인하고 시작하기` → 공용 로그인 모달)을 본다(REQ-LCSK-24). 이 주소는 검색엔진에 노출하지 않는다(`routeSeo.js`).
- `/legend-collection-skills` 는 읽기 전용 목록이 됐다. 행을 누르면 `/legend-collection-skills/:legendId/edit` 레전드 한 명 편집 화면으로 간다(REQ-LCSK-13·28). 목록 아래에 "보유 현황 기준 N명 · 보유 현황에서 바꾸기 →"(→ `/legend-collections/manage`)를 둔다(REQ-LCSK-27).
- 필터는 검색을 품은 공용 필터 영역(칩 항상 펼침)이다(REQ-LCSK-26). 요약 줄 왼쪽은 "등록 n · 미등록 n", 오른쪽은 현재 정렬 기준 텍스트다(REQ-LCSK-29).
- 목록 표 머리 정렬을 추가했다 — 레전드·강화(미등록은 항상 뒤)·상태(보유중/액자 먼저)·등록여부(등록/미등록 먼저), 기본 `상태 · 보유중 먼저`(REQ-LCSK-23).
- 사용자 확정(2026-10-03): 문서 제목 "내 기록 관리"·"스킬 기록 편집"은 현재 값 유지, 선호 0명 칩은 눌러서 빈 안내를 보여 주는 동작 유지.
- 홈 "내 컬렉션" 카드용 스킬 등록 수 요약 훅(`useMySkillSummary.js`)을 추가했다.
- 되돌린 결정(같은 브랜치 안): 공용 탭 4개 → 3개 · 필터 접기 → 항상 펼침 · 가이드 `?` 아이콘 → 아코디언 · 부제 추가 → 삭제. 이유는 ADR 0010 "되돌린 결정".

**손대지 말 것**

- 스킬 계산·강화 규칙·BE API·권한은 바뀐 것이 없다. 보유·액자 상태는 이 화면에서 바꾸지 않는다.

**미결**

- 새 화면 Figma 시안은 갱신 중(레전드 재료 섹션 node 522:2650). 결정 근거는 ADR 0010.

## 2026-10-02 — 내 레전드 스킬 기록 첫 출시

- 버전: 1.0.0 (minor, 신규 화면)
- 커밋: `cdc8cae1`(sql) · `baa3c066`(be) · `086c49aa`(web)

**고친 것**

- 로그인한 이용자가 보유중·액자 레전드의 스킬 3개와 등록 등급을 저장하고, 기본 강화·고추강·고고각 버튼으로 현재 등급을 올려 기록하는 새 화면 `/legend-collection-skills` 를 만들었다. 강화는 화면에 모았다가 `저장` 한 번에 서버로 보낸다(전부 성공하거나 전부 취소).
- 등록 등급 기준으로 풀업에 필요한 고고각·고추강 수와 쓴 수를 계산해 보여 준다. 일괄 적용 2종(S 일괄·고고각 제외), 되돌리기, 스킬 초기화, 이 페이지 활용 가이드(스타 경험치 표 포함)를 넣었다.
- 목록은 `# | 레전드 | 강화 | 상태 | 등록여부` 순이고 보유중을 먼저 보여 준다. "강화" 열은 현재 등급 글자를 스킬 등급 색으로 칠한다. 필터는 전체·등록·미등록.
- 메뉴에 "내 레전드 스킬 기록"(로그인 필요)을 추가했다. 메뉴·라우트·store 등록은 앱 공통 영역에서 한 일이라 이 기능 문서가 아닌 앱 설정에 있다.
- 새 테이블 2개: `site_user_legend_skills`(현재 상태), `site_user_legend_skill_logs`(강화 기록). DB 에는 사용자가 직접 적용했다(2026-10-02).

**손대지 말 것**

- 되돌리기·스킬 초기화는 로그를 지운다(남기지 않는다). 강화 횟수 집계는 마지막 `SAVE` 이후 로그만 센다.
- 액자 레전드는 등록·초기화만 되고 강화는 거부된다(서버가 상태를 다시 검사).
- 스킬 카드(`SkillCard`)는 데이터를 받아 그리기만 한다 — 이후 "내 덱 보여주기"가 그대로 쓴다.

**미결**

- 전체 이용자 통계 편입·SEO 문구(spec ❓ LCSK-Q8).
- 다른 기기 동시 수정 경고는 서버가 아직 내지 않는다(화면은 409 문구를 보일 준비만 됨).
