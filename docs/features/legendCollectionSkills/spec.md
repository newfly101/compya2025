# legendCollectionSkills

## 1. 무엇을 하는 기능인가

로그인한 이용자가 보유·액자 레전드의 **고유능력(스킬) 3개와 등록 등급**을 저장하고, 키우면서 **현재 등급을 버튼으로 한 단계씩** 올려 가며 기록하는 기능이다. 등록 등급 기준으로 풀업(스킬 3개를 각자 최대 등급까지 올리기)에 필요한 강화 재화(고유능력 추가 강화권·고급 고유능력 각성권)를 계산해 "사용/필요"로 보여 준다.
`legendCollections`("레전드 재료 보유 현황") 화면의 확장이며, 키울 선수의 변경·강화 히스토리를 쌓는 단계다. 보기 화면은 레전드 카드 이미지 위에 이름·강화 횟수·스킬 3개(현재 등급)를 얹은 "스킬 카드"(참고 `16.png`)이고, 이후 "내 덱 보여주기"(이미지 저장)에서 그대로 다시 쓴다.

용어: **등록 등급** = 스킬을 등록할 때 넣는 등급(획득 시점 기준). **현재 등급** = 강화해 올린 지금 등급. **고추강** = 고유능력 추가 강화권. **고고각** = 고급 고유능력 각성권. **스킬 등급** = 스킬 자체의 종류(노말·히어로·플래티넘·레전드)이며 강화 등급(E~S)과 다르다. **풀업** = 스킬 3개를 각자 최대 등급까지 올리는 것.

## 2. 화면과 진입 경로

| 화면 | 주소 | 어디서 들어오나 |
|---|---|---|
| 내 레전드 스킬 기록(목록) | `/legend-collection-skills` (화면 번호는 아직 없음) | 메뉴의 "내 레전드 스킬 기록" 또는 "레전드 재료 보유 현황" 화면 제목 아래 "내 레전드 스킬 기록 →" 링크. 로그인한 이용자만 들어올 수 있다 |
| 스킬 보기·편집 | 같은 화면, 행을 펼친 영역 | 목록에서 보유중·액자 레전드 행을 누르면 펼쳐지고 스킬 카드와 편집 패널이 함께 보인다. 미보유는 목록에 없다 |

별도 `편집` 버튼은 없다. 행을 펼치면 바로 편집할 수 있다. 펼침 영역 = 왼쪽 스킬 카드 + 오른쪽 "스킬 등록 목록"(스킬·등급 드롭다운 3줄)·필요 재화·버튼.

## 5. 하지 않는 것

- **획득 시점 등급 복원** — 이미 강화된 레전드의 과거 등급을 되짚지 않는다(일괄 적용 두 버튼으로 대신함).
- **스타 경험치 기록** — 활용 가이드의 비용표 안내만 둔다. 강화 횟수는 로그 집계로만 보여 준다.
- **변경권 횟수 · 재화 총량 · 획득/소모 일시** — 이후 별도 테이블로 다룬다.
- **내 덱 보여주기·이미지 저장** — 이후 기능. 카드 부품만 재사용 가능하게 만든다. 아래는 사용자가 확정한 규칙으로, **이번 범위가 아니며 덱 기능을 만들 때 스킬 카드(`SkillCard`)에 적용**한다.

  | 카드 종류 | 스킬 슬롯 | 가질 수 있는 최고 스킬 등급 |
  |---|---|---|
  | 레전드 | 3 | 레전드 (레전드 스킬은 레전드 카드만) |
  | 시그니처·플래티넘 | 3 | 플래티넘 |
  | 히어로 | 3 | 히어로 |
  | 스페셜 | 2 | 노말 |
  | 노말 | 1 | 노말 |

  - 슬롯이 1·2개면 위에서부터 채운다.
  - 풀업 표기: 레전드·플래티넘 스킬은 S, 히어로·노말 스킬은 A.
  - 카드 안 스킬 중복 금지, 투수/타자 스킬 구분.
  - 시안: Figma `legendCollectionSkills / 내 덱 샘플` node `491:643` (이미지 export 용).
- 레전드 외 카드의 스킬 기록 · 스킬 효과 수치 계산(`playerSkills` 담당) · 재료 획득처·가격 안내.
