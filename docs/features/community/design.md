# 커뮤니티 — 설계

> 동결 도메인. 아래는 현재 배포된 읽기 전용 화면의 실측 상태만 기록한다. `community` 도메인은 디자인 규칙 적용 대상에서도 제외돼 있다(`fe-design.md`).

## 1. 화면 구조

| 화면 ID | 화면 | 영역 배치 |
|---|---|---|
| SC-05-01 | 커뮤니티(읽기 전용) | 카테고리 칩 행(게시판 목록) → 섹션(선택된 게시판 이름 + 게시글 총 건수) → 게시글 행 목록 |

## 2. 상태

| 상태 | 조건 | 화면에 보이는 것 |
|---|---|---|
| 불러오는 중 | `loading` | "불러오는 중입니다." |
| 오류 | `error` | "게시글을 불러오지 못했습니다." |
| 빈 화면 | 게시글 0건 | "등록된 게시글이 없습니다." |
| 정상 | 게시글 있음 | 게시글 행 목록 렌더 |

## 3. 흐름

```mermaid
flowchart TD
    A[/community 진입] --> B[게시판 목록 조회]
    B --> C[첫 게시판 선택]
    C --> D[해당 게시판 게시글 목록 조회]
    D --> E{상태}
    E -- 로딩 --> F[불러오는 중]
    E -- 오류 --> G[불러오지 못함]
    E -- 0건 --> H[등록된 게시글 없음]
    E -- 정상 --> I[게시글 행 목록]
    I --> J[행 클릭]
    J --> K{linkType=EXTERNAL?}
    K -- 예 --> L[새 탭으로 원문 열기]
    K -- 아니오 --> M[동작 없음 - 상세 라우트 없음]
```

## 4. 디자인 값

동결 도메인은 `fe-design.md` 적용 대상이 아니라 별도 확인 생략. 도메인 로컬 토큰(`community.tokens.scss`) 존재 확인만 하고 값 변경은 이 라운드 범위 밖.

## 5. 서버와 주고받는 것

| 요청 | 응답 | 실패하면 |
|---|---|---|
| `GET /api/boards` | 게시판 목록 | 카테고리 칩 미노출 |
| `GET /api/posts/boards/{boardId}` | 게시글 목록 | "게시글을 불러오지 못했습니다." |
