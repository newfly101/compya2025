# 커뮤니티

## 1. 무엇을 하는 기능인가

v1에서 이관된 게시글을 읽기 전용으로 볼 수 있는 게시판이다. 글쓰기·댓글·좋아요 같은 쓰기 기능은 서비스되지 않는 동결 상태다. 이관된 게시글 237건은 전부 본문 없는 외부 링크(북마크)라, 목록에서 클릭하면 원문 링크가 새 탭으로 열린다.

## 2. 화면과 진입 경로

| 화면 | 주소 | 어디서 들어오나 |
|---|---|---|
| SC-05-01 커뮤니티(읽기 전용) | `/community` | 공개(홈 메뉴·서랍) |

## 3. 규칙

| ID | 항목 | 규칙 | 근거 |
|---|---|---|---|
| REQ-CMT-01 | 읽기 전용 재오픈 | 글쓰기·댓글·좋아요를 붙이지 않는다 — v1 게시글 전부 본문 없는 외부 링크라 쓰기 기능이 필요 없다 | `CommunityScreen.jsx` 주석(2026-08-31) |
| REQ-CMT-02 | 외부 링크 이동 | v1 이관 게시글(`linkType=EXTERNAL`)을 클릭하면 새 탭으로 원문을 연다. 그 외 타입은 상세 화면 라우트가 없어 아무 동작도 하지 않는다 | `CommunityScreen.jsx` `handlePostClick` |
| REQ-CMT-03 | 카운트 조작 방지 | 댓글 좋아요·싫어요·신고 수를 올리는 API 5개는 로그인 확인을 거쳐야 한다(과거 로그인 없이 반복 호출로 조작 가능했던 문제를 수정) | `docs/features/community/history.md` 2026-09-28(`e4ec4208`) |
| REQ-CMT-04 | 관리자 화면 이중 방어 | 관리자 전용 API 6곳에 권한 검사를 이중으로 둔다(현재 이미 다른 규칙으로 막혀 있으나, 매처 순서가 바뀔 미래에 대비) | `docs/features/community/history.md` 2026-09-28(`e4ec4208`) |

## 4. 데이터

| 무엇 | 테이블 · API | 비고 |
|---|---|---|
| 게시판 목록 | `GET /api/boards`, `GET /api/boards/{id}`, `GET /api/boards/code/{code}` | 조회 전용 |
| 게시글 목록 | `GET /api/posts/boards/{boardId}`(+`/pinned`, `/popular`), `GET /api/posts/{id}` | 조회 전용. FE는 목록만 사용, 상세 라우트 없음 |

## 5. 하지 않는 것

- 글쓰기·댓글·좋아요·신고 화면 — 동결 상태라 FE 코드 자체가 없다. 재오픈 시점·방식은 사용자 결정 대기 (§6)
- 반응(좋아요·싫어요·신고) 카운트 구조 근본 개선(반응 기록 테이블 경유) — 동결 도메인이라 기능 재개 결정과 함께 논의해야 할 범위 밖 작업

## 6. 확인 필요

- ❓ 커뮤니티 쓰기 기능(글쓰기·댓글·좋아요) 재오픈 여부·시점·본인확인 방식 미정 (`roadmap.md` § 6 D-01)
- 로그인한 사용자 1명이 반복 호출로 반응 카운트를 조작하는 것은 REQ-CMT-03 수정 후에도 여전히 가능하다 — 근본 해결은 기능 재개 결정 이후 별도 작업
