# community — 변경 이력

> `community`는 현재 동결된 기능이다(글쓰기·댓글·좋아요 등 쓰기 기능 자체가 서비스되지 않음). 이 기록은 전역 코드 리뷰 라운드에서 이 기능의 코드에 발견된 보안 항목 1건만 다룬다.

## 2026-09-28 — 댓글 카운트 조작이 로그인 없이 가능했음

- 버전: 1.0.1 (patch)
- 커밋: `e4ec4208`

**고친 것**

- 댓글 좋아요·싫어요·신고 수를 올리는 API 5개가 로그인 여부를 확인하지 않아, 같은 요청을 반복하기만 해도 카운트를 임의로 조작할 수 있었다. 같은 클래스의 다른 쓰기 기능처럼 로그인 확인을 추가했다.
- 관리자 전용 화면 API 6곳에도 이중 방어용 권한 검사를 추가했다 — 지금 당장 뚫려 있는 건 아니지만, 앞으로 보안 설정 순서가 바뀔 미래에 대비한 것이다.

**손대지 말 것**

- 이 기능은 동결 상태라 화면(FE)에 댓글·반응 관련 코드 자체가 없다 — 이번 수정은 서버 코드만 바꿨고 화면에 미치는 영향은 없다.
- 근본적인 해결(반응 기록 테이블을 거치도록 구조 변경)은 기능 자체를 다시 켜는 결정과 함께 논의해야 한다 — 이번 라운드 범위 밖.

**미결**

- 로그인한 사용자 1명이 반복 호출로 카운트를 조작하는 것은 여전히 가능하다. 근본 해결은 반응 테이블 경유 구조로 바꾸는 것인데, 동결 도메인이라 기능 재개 결정이 먼저 필요하다.
