# legendCollections

## 1. 무엇을 하는 기능인가

로그인한 이용자가 레전드마다 "액자 보유", "레전드 보유", 재료카드 8칸(선수 6 + 코치 세트 2)의 "보유 / 삽입" 상태를 서버에 저장해 두는 기능이다.
이미 레전드를 가진 사람이 아직 없는 레전드를 얻으려 할 때, 미보유 레전드 중 어디에 재료를 몰아 모을지 판단하도록 돕는다.
조회 화면은 보기 전용이고, 기록은 `관리` 화면에서 한다. 선호 레전드(최대 10)는 `선호` 모달에서 골라 `선호 N` 칩으로 그 레전드만 모아 보고, 홈 화면은 오늘 히스토리 모드에서 뽑아야 할 내 재료와 이번 주기 일정을 알려 준다.
게임에서는 재료 8칸을 모두 삽입하면 레전드 카드를 얻고, 삽입한 재료카드는 소모된다. 액자(레시피)는 스카웃 확률로 얻거나 유료 재화로 만들 수 있다.

## 2. 화면과 진입 경로

| 화면 | 주소 | 어디서 들어오나 |
|---|---|---|
| 내 재료 보유 현황 — 조회 (읽기 전용) | `/legend-collections` (`?tab=mine` 은 `선호 N` 칩이 켜진 채, `?prefs=1` 은 선호 모달이 열린 채 열린다) | 서랍 "레전드 재료 › 내 재료 보유 현황", 공용 탭 "내 보유 현황", 홈 "내 컬렉션" 카드·바로가기, 마이페이지 "내 선호 레전드"와 홈 오늘 히스토리 카드의 "내 선호 보기 →"(둘 다 `?tab=mine`) |
| 보유 현황 관리 (편집) | `/legend-collections/manage` | 조회 화면 검색 줄의 `관리` 버튼, 스킬 기록 화면의 "보유 현황에서 바꾸기 →". 첫 입력(1회차)도 여기서 한다 |
| 선호 설정 (모달) | 별도 주소 없음(조회 화면 위에 뜬다) | 검색 줄의 `선호` 버튼, 첫 저장 직후 확인창의 "고르러 가기"(`?prefs=1`) |
| 홈 "오늘 히스토리 모드" 카드 · "이번 주기 일정" 섹션 | `/` (홈, 공지사항 다음) | 로그인 + 선호 레전드가 있을 때만. 위치는 `home` REQ-HM-13·16 |

## 5. 하지 않는 것

- 전날 예고 알림·푸시 알림 — 당일 홈 카드와 홈 주기 일정으로 충분하다고 봤다.
- 중복 재료 개수 관리 — 칸 하나 = 상태 하나로 단순하게 간다.
- 전체 유저 통계 — 개인 기록 저장에 집중한다.
- 게임 계정 연동 자동 동기화 — 공식 연동 수단이 없다.
- 삽입 상태의 개별 되돌리기(저장 후) — 실수 복구는 전체 초기화 하나로 한정한다.
- 보유 현황 안의 "이번 주기 일정" 카드 · 선호 설정 페이지(`/goals`) · 본문 부제 · 필터 접기 — 2026-10-02 되돌린 결정(`0010`).
