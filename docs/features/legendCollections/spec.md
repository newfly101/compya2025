# legendCollections

## 1. 무엇을 하는 기능인가

로그인한 이용자가 레전드마다 "액자 보유", "레전드 보유", 재료카드 8칸(선수 6 + 코치 세트 2)의 "보유 / 삽입" 상태를 서버에 저장해 두는 기능이다.
이미 레전드를 가진 사람이 아직 없는 레전드를 얻으려 할 때, 미보유 레전드 중 어디에 재료를 몰아 모을지 판단하도록 돕는다.
처음 한 번 전체 레전드의 재료를 입력하고 나면, 선호 레전드(최대 10)를 골라 "내 목표" 화면에서 그 레전드만 관리하고, 홈 화면은 오늘 히스토리 모드에서 뽑아야 할 내 재료를 알려 준다.
게임에서는 재료 8칸을 모두 삽입하면 레전드 카드를 얻고, 삽입한 재료카드는 소모된다. 액자(레시피)는 스카웃 확률로 얻거나 유료 재화로 만들 수 있다.

## 2. 화면과 진입 경로

| 화면 | 주소 | 어디서 들어오나 |
|---|---|---|
| 레전드 재료 보유 현황 — "전체" 탭 (화면 번호는 개발 시 부여) | `/legend-collections?tab=all` | 기존 "레전드 재료 검색"(`/legend-stats`) 화면의 연결 버튼. 첫 입력(1회차)은 이 탭에서 한다 |
| 내 목표 — 선호 레전드 탭 🟨 | `/legend-collections?tab=mine` | 선호 레전드가 1명 이상이면 기본 탭. 마이페이지의 "내 레전드 목표" 링크 🟨 |
| 선호 레전드 고르기 (가운데 모달) | 내 목표 탭 안 | 첫 입력 저장 직후 1회 권유, 이후 내 목표 탭의 "선호 편집" 버튼. 후보는 미보유 레전드만. 여기서 레전드마다 액자도 바로 켜고 끈다 |
| 홈 "오늘 히스토리 모드" 카드 | `/` (홈) | 로그인 + 선호 레전드가 있고, 오늘 명단에 내 미보유 재료가 있을 때만 보인다 |

| REQ-LCOL-06 | 상태 전환과 재료 | 미보유→보유중, 액자→보유중: 저장 시 그 레전드의 재료 8칸을 **0/8로 초기화**(저장된 삽입 포함)하고 상태를 보유중으로 표기한다. 보유중 레전드의 재료 버튼은 잠긴다. 선호였다면 선호에서 자동으로 빠진다(REQ-LCOL-17). 확인창은 띄우지 않는다 — 켜진 `보유중`을 한 번 더 누르면 미보유로 돌아가므로 편집 중에 바로 되돌릴 수 있다. 액자→미보유: 재료는 건드리지 않는다(삽입 4장이면 그대로 4장) | 사용자 확정 2026-09-29 |

| REQ-LCOL-08 | 편집 흐름 | 편집 모드는 전체 레전드를 대상으로 **재료 칸 상태와 레전드 상태**를 바꾼다. 열람 화면의 `편집` 버튼 자리에 편집 중에는 "저장 안 한 변경 N" · `취소` · `저장` 이 나온다(하단 고정 바 없음). 저장 버튼을 눌러야만 서버 호출이 일어난다. 편집 중 임시값은 브라우저 sessionStorage(탭 안에만 잠시 보관하는 저장소)에 둔다. 새로고침·페이지 이탈 시 저장 안내 팝업을 띄운다 | 사용자 확정 2026-09-29 |
| REQ-LCOL-09 | 저장 권한 | 로그인한 이용자만 저장할 수 있다. 서버는 로그인한 본인의 기록만 읽고 쓴다 | 확정 |

| REQ-LCOL-18 | 내 목표 화면 | 탭 아래 **"이번 주기 일정"** 은 기본이 접힘이다. 접힘: 오늘 선호 레전드 재료가 히스토리 명단에 있으면 오늘 줄 하나만, 없으면 "오늘 획득할 수 있는 선호 레전드 재료 카드가 없습니다" 문구만 보인다. 접힘 상태는 스크롤해도 화면 상단에 붙어 있다. `전체 일정 펼치기` 를 누르면 14일 주기 전체 일정이 펼쳐지고 `접기` 로 닫는다. 일정의 각 날짜 아래 한 줄은 **레전드 이름(굵게)과 재료 카드 두 칸**이다(예: `● 최동원   김민호'92`, 구분 기호 없음). 그 아래 필터는 `전체` · `액자 보유` · `미보유` 세 개. **`전체` 는 선호 순위대로 한 줄로 나열**하고, `액자 보유`/`미보유` 를 고를 때만 그 묶음만 보인다. 선호 레전드 카드는 진행률과 남은 재료를 보여 주고, 남은 재료는 열람 화면과 같은 **2열 재료 카드**(`마`·`히` 태그 포함)로 펼친다 | 사용자 확정 2026-09-29 |
| REQ-LCOL-19 | 히스토리 일차 계산 | 히스토리 모드는 14일 주기(1일차=월요일, `historyLegend` REQ-HL-06). 코드에 고정 기준일 **2026-09-28(월) = 1일차** 를 두고 `(오늘 - 기준일) mod 14 + 1` 로 오늘 일차를 구한다. 2주마다 돌아오는 월요일은 항상 1일차다. 날짜는 한국 시간(KST) **00:00** 에 바뀐다 | 사용자 확정 2026-09-29 |
| REQ-LCOL-20 | 홈 오늘 안내 | 홈에 "오늘 히스토리 모드" 카드를 둔다. 대상은 선호 레전드 전체의 미보유 재료 중 오늘 일차 명단(`data_history_roster`, 선수 이름+연도로 재료와 연결)에 있는 것. 액자 있는 레전드의 재료를 먼저, 그 아래 액자 없는 레전드의 재료를 **접지 않고 모두** 보여 준다(카드가 길어져도 한눈에 보이는 것을 우선). 한 줄 = 라운드 · 카드 · 필요한 레전드. 누르면 히스토리 재료 화면(`historyLegend`)으로 간다. 해당 재료가 없거나 비로그인·선호 0명이면 카드를 숨긴다 | 사용자 확정 2026-09-29 |

## 5. 하지 않는 것

- 전날 예고 알림·푸시 알림 — 당일 홈 카드와 내 목표의 주기 일정으로 충분하다고 봤다.
- 중복 재료 개수 관리 — 칸 하나 = 상태 하나로 단순하게 간다.
- 전체 유저 통계 — 개인 기록 저장에 집중한다.
- 게임 계정 연동 자동 동기화 — 공식 연동 수단이 없다.
- 삽입 상태의 개별 되돌리기(저장 후) — 실수 복구는 전체 초기화 하나로 한정한다.
