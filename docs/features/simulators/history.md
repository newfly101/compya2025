# simulators (스킬 시뮬레이터) — 변경 이력

## 2026-10-27 — 고스변 시뮬레이터 화면 (선수 고르기 · 돌리기 · 선변 · 이미지 저장)

- 버전: 0.2.0 (minor)
- 커밋: 38af6d47 · 5b517093 (초기화가 진행 중인 자동 저장 뒤에 삭제되도록 수정)

**고친 것**

- `/simulators/gsb` 화면을 새로 만들었다. 레전드 선수를 구단·타자/투수·포지션·이름으로 골라, 고급 고유능력 변경권(고스변)으로 스킬 3개를 한 번에 뽑고, 선택 변경권(선변)으로 고른 한 칸만 다시 뽑는다. 선수별 누적 횟수와 마지막 스킬이 남는다.
- 뽑기 규칙은 게임 공지 확률표 그대로다. 같은 이름 스킬은 한 카드에 두 번 나오지 않고, 선변에서는 레전드 스킬이 나오지 않는다. 규칙 검사 파일 `config/gsb.test.js` 도 함께 넣었다.
- 로그인한 이용자만 쓴다. 비로그인은 같은 주소에서 로그인 안내 화면을 본다. 서버 기록은 마지막 변경 10초 뒤 · 화면을 가리거나 떠날 때 바뀐 선수만 묶어서 저장한다(돌릴 때마다 보내지 않는다).
- 이미지 저장은 기기에서 직접 그린 PNG 를 공유 창으로 보내고, 공유가 안 되는 기기는 파일로 내려받는다. 저장 기록 서버 전송은 실패해도 이미지 저장은 그대로 진행한다.
- 스킬 카드 부품을 `global/ui/skillCard/` 로 옮겼다(레전드 재료 스킬 기록 화면은 동작 그대로). 강화 횟수 줄 숨김 · 고스변/선변 누적 박스 · 닉네임 · 칸 선택(테두리만 구분) 옵션을 더했다.
- 선변 버튼의 금색 면 토큰 `--color-grade-platinum-alpha-15` 를 추가했다(`fe-design-audit.md` 예외 표 동기화).

**손대지 말 것**

- 선변 버튼의 금색은 등급 색을 등급 밖에 쓰는 유일한 예외다. 다른 버튼에 퍼뜨리지 않는다.
- 카드의 스킬 옆 등급 글자(E·C 같은)는 저장하지 않는 값이라 그리지 않는다. 서버에도 스킬 id 3개만 간다.
- 선수 칩 부품(`FilterChips`)은 다른 도메인 것을 그대로 가져다 쓴다(레전드 스킬 기록 화면과 같은 방식). 공용으로 옮길 때 한 번에 정리한다.

**미결**

- 서버가 떠 있는 상태에서의 실제 동작(조회·묶음 저장·이미지 저장 기록)과 두 테마·320px 화면 확인은 못 했다. 빌드와 뽑기 규칙 검사만 통과.
- 저장 기록 테이블이 만들어지기 전에는 이미지 저장 기록 전송이 실패한다(화면은 무시).

## 2026-10-27 — 고스변 시뮬레이터 서버 (내 기록 저장·조회·초기화, 이미지 저장 기록)

- 버전: 0.1.0 (minor)
- 커밋: 5c1cd914 (sql b3085a07)

**고친 것**

- 로그인한 이용자의 고스변 기록(선수별 고스변·선변 횟수, 스킬 3칸)을 서버에 저장하고 불러오고 선수별로 지울 수 있다. 기록은 Valkey(빠른 임시 저장소)에 30일 보관하며, 저장할 때마다 30일이 다시 시작된다.
- 이미지 저장을 누른 기록을 DB 에 한 줄씩 쌓는 API 를 추가했다. 레전드·스킬이 없는 id 면 404 로 거절한다.
- 주소는 `/api/simulators/gsb` (조회 GET · 묶음 저장 PUT · 선수별 초기화 DELETE · 저장 기록 POST `/saves`). 로그인 없으면 전부 401.
- 묶음 저장은 한 번에 100명까지, 횟수는 0~9,999,999, 스킬은 정확히 3개만 받는다.
- 기록 테이블 생성문을 `sql/draft/pending/site_user_simulator_saves.sql` 에 작성만 했다(실행 안 함).

**손대지 말 것**

- 저장 기록 테이블은 사용자가 직접 실행해야 한다(test·운영 DB 동일). 실행 전에는 POST `/saves` 가 오류를 내지만 화면은 이 실패를 무시하게 되어 있다.
- 저장소 키에 이메일이 들어간다(설계 확정). 로그·응답에 키를 그대로 남기지 않는다.
- 횟수·스킬 조합은 이용자가 보낸 값을 그대로 믿는다. 존재 여부만 확인한다.

**미결**

- 서버 구동 후 실제 호출(쿠키 없이 401, 로그인 후 4개 엔드포인트) 확인은 아직 못 했다. 컴파일만 통과.
