# simulators (스킬 시뮬레이터)

## 1. 무엇을 하는 기능인가

레전드 선수 1명을 골라 고급 고유능력 변경권(고스변)과 고유능력 선택 변경권(선변)을 가상으로 돌려 보는 시뮬레이터다. 이번 범위는 고스변이 중심이며 선변은 같은 화면에서 쓴다. 보호 변경권은 다음 작업이다. 로그인한 사람만 쓸 수 있다. 공식 데이터가 아니라 게임 공지 확률표를 따른 비공식 모의 도구다.

## 2. 화면과 진입 경로

| 화면 | 주소 | 어디서 들어오나 |
|---|---|---|
| 고스변 시뮬레이터 (SC-19-01) | `/simulators/gsb` | 주소 직접 입력. 서랍 메뉴 노출은 아직 안 함(메뉴의 "스킬 시뮬레이터 준비중" 항목은 옛 자리 표시) |

사용 흐름

1. 레전드 선수 고르기 — 구단 · 타자/투수 · 포지션 칩, 이름 검색, "N명 · 평점 미정 M", 정렬 "평점 높은순", 선수 카드 가로 스크롤.
2. 고스변 버튼 — 스킬 3개가 한꺼번에 새로 정해지고 고스변 횟수가 1 늘어난다(레전드 → 플래티넘 → 노말/히어로 순 정렬).
3. 선변 버튼 — 선택 모드가 된다. 스킬 1칸을 고르고 "변경"을 누르면 그 칸만 다시 정해진다(선변 횟수 +1). "취소"하면 아무것도 바뀌지 않는다.
4. 초기화 — 확인 창 뒤 그 선수의 횟수·스킬 기록을 지운다.
5. 이미지 저장 — 카드 그림(스킬 3줄 · 횟수 · 닉네임)을 내려받거나 공유한다.
6. 비로그인은 같은 주소에서 로그인 안내 화면을 본다.

## 3. 규칙

| ID | 항목 | 규칙 | 근거 |
|---|---|---|---|
| REQ-SIM-01 | 고스변 등급 조합 | 아래 9가지를 공지 확률대로 뽑는다(레전드/플래티넘/노말·히어로 칸 수, %): 0/1/2 33.5851 · 0/2/1 16.1208 · 1/0/2 18.0843 · 1/1/1 18.8076 · 2/0/1 4.3402 · 0/3/0 2.2734 · 1/2/0 4.3402 · 2/1/0 2.1701 · 3/0/0 0.2782. 합계 99.9999 의 나머지 0.0001 은 마지막 행에 더한다 | `web/src/domains/simulators/config/gsb.js` |
| REQ-SIM-02 | 칸별 추첨 | 칸마다 그 등급 풀에서 균등 추첨. 노말+히어로 26 · 플래티넘 13 · 레전드 7 (타자·투수 각각) | `gsb.test.js` |
| REQ-SIM-03 | 같은 이름 금지 | 같은 이름의 스킬은 등급이 달라도 한 카드에 둘 나오지 않는다 | `gsb.test.js` |
| REQ-SIM-04 | 독립 시행 | 매 회 독립이다 | `gsb.js` |
| REQ-SIM-05 | 선변 | 고른 칸만 노말·히어로·플래티넘 39개 풀에서 뽑고, 지금 3칸과 이름이 같은 스킬은 모두 뺀다(레전드는 나오지 않는다) | `gsb.test.js` |
| REQ-SIM-06 | 기록 보관 | 기록은 로그인한 사람만 저장하고 30일 보관하며 저장할 때마다 30일로 다시 센다 | `SimulatorRepository` |
| REQ-SIM-07 | 묶음 저장 | 돌릴 때마다 저장하지 않고 바뀐 선수만 모아 마지막 변경 10초 뒤 · 탭이 숨겨질 때 · 화면 이탈 때 한 번에 저장한다 | `useGsbSync.js` |
| REQ-SIM-08 | 저장 기록 | 이미지 저장을 누를 때마다 서버에 기록 1행(선수 · 그때의 횟수 · 스킬 3개)을 남긴다. 기록 화면은 아직 없다. 기록 전송이 실패해도 이미지 저장은 진행한다 | `useGsbSimulator.js` |
| REQ-SIM-09 | 공유 링크 없음 | 공유 링크는 만들지 않는다(주소에 담은 값을 고칠 수 있어서). 횟수·스킬은 이용자 기기가 계산하므로 조작 가능하며 순위·보상에 쓰지 않는다 | gsb-rules |

## 4. 데이터

| 무엇 | 테이블 · API | 비고 |
|---|---|---|
| 내 기록 조회·저장·초기화 | `GET`·`PUT /api/simulators/gsb` · `DELETE /api/simulators/gsb/{legendId}` | Valkey Hash, 30일 |
| 이미지 저장 기록 | `POST /api/simulators/gsb/saves` → `site_user_simulator_saves` | 덧붙임 전용. 테이블은 사용자 실행 대기 |
| 스킬 · 레전드 목록 | `/api/player-skills/{hitters,pitchers}` · `/api/legend-stats` | 기존 API 재사용 |

## 5. 하지 않는 것

- 에픽 5성 · 5성 미만 확률표, 보호 변경권 — 이번 범위 밖
- 공유 링크 — 값 조작 우려
- 서버 이미지 생성 — 이용자 기기에서 그린다
- 저장 기록 보기 화면 — 쌓기만 한다
