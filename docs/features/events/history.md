## 2026-09-28 — 편집 저장이 손대지 않은 종료 시각을 덮어씀 외 4건

- 버전: 1.0.1 (patch)
- 커밋: `22b247bf`

**고친 것**

- 이벤트 제목만 고쳐 저장해도 종료 시각이 자동으로 그날 23:59:59로 밀렸다. 편집 폼에 시각 입력(선택) 칸을 추가해, 비워두면 원본 시각이 그대로 유지되게 했다.
- 내부 전용(INTERNAL) 이벤트가 노출 토글 하나만으로 공개 화면에 샐 수 있는 구조였다. 공개 조회 쿼리에 "공식 이벤트만" 조건을 추가해 원천 차단했다.

- 관리자·공개 화면의 만료 판정 기준이 날짜 단위/분 단위로 서로 달라 같은 이벤트가 다르게 보일 수 있었다 — 쿠폰 기능과 같은 원인이라 같은 방식(분 단위 통일)으로 맞췄다.
