# odds — 변경 이력

## 2026-09-28 — 확률 공시 메뉴의 "로그인 필요" 표시를 실제 동작에 맞춤

- 버전: 1.0.1 (patch)
- 커밋: `e40f7bb0`

**고친 것**

- odds(확률 공시, `/probability`) 도메인 코드 자체(`web/src/domains/odds/**`)는 이번 라운드에 한 줄도 고치지 않았다 — 리뷰에서 결함을 찾지 못했다.
- 다만 odds를 "로그인 필요"로 안내하던 서랍 메뉴·홈 빠른 메뉴 설정 파일(`MENU_GROUPS.js`, `QUICK_MENUS.js`)의 `loginRequired` 속성을 지웠다. 확률 공시는 게임사가 법적으로 공개해야 하는 자료라 로그인 여부와 무관하게 누구나 볼 수 있어야 하는데, 정작 라우트에는 인증 가드가 없으면서 메뉴에서만 로그인을 요구하던 모순을 없앤 것 — odds 코드가 아니라 odds에 대한 서술(메뉴 문구)을 실제 동작에 맞췄다.

**손대지 말 것**

- `/probability` 라우트에 인증 가드를 새로 넣지 말 것 — 확률 공시는 로그인 없이 누구나 볼 수 있어야 하는 것이 맞는 설계다. 예전 리뷰 문서의 "가드가 없다 = 확인 필요"라는 서술은 이미 답이 난 사안이니 다시 문제로 보지 말 것.
- `OddsTable.jsx`의 `computeGridColumns`(표 병합 계산)는 복잡해 보이지만 실제 HTML 표의 rowSpan/colSpan 규칙을 그대로 옮긴 것이다. 단순화하면 5열 이상 넓은 표의 셀 병합이 깨진다.
- 확률 수치(범위 텍스트) 합이 100%가 안 되는 것처럼 보여도 고치지 말 것 — 소수점 최대 8자리까지만 표시한다는 안내가 이미 있는 정상 상태다.

**미결**

- 없음. odds 도메인은 코드 문제도 결정 대기 항목도 남아 있지 않다.
