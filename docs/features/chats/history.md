# chats (펀톡) — 변경 이력

## 2026-10-08 — 펀톡 첫 구현: 우측 하단 플로팅 카드에서 모두가 한 방에서 대화

- 버전: 0.1.0 (minor)
- 커밋: `7f74601c` (be) `ec10af18` (web)

**고친 것**

- 사이트 어디서나 우측 하단 버튼을 누르면 펀톡 카드가 열린다. 방은 하나(lobby)이고, 비로그인은 읽기만, 로그인하면 쓸 수 있다.
- 닉네임이 `***` 로 끝나는(마스킹된) 사용자는 쓸 수 없고 마이페이지로 닉네임 변경을 안내한다.
- 글은 200자·5줄, 한 사람당 3초에 1건. 입력창은 내용에 맞춰 늘어나고(약 4줄 넘으면 안에서 스크롤) 글자 수는 입력창 안 우측 하단에 보인다. Enter 전송, Shift+Enter 줄바꿈, 한글 조합 중 Enter 는 전송하지 않는다. HTML 태그 모양(`<b>`, `</div>`, `<!--`)이 들어간 글은 화면과 서버 양쪽에서 막는다. `<3`, `a < b` 같은 문장은 통과.
- 내역은 DB 에 저장하지 않는다. 같은 서버의 Valkey(Redis 호환)에 최근 100개만 두고, 서버 간 전달은 Pub/Sub(구독·발행) 으로 한다. Valkey 를 재시작하면 내역이 사라진다(의도).
- 내 글 / 남의 글 / 봇 글을 말풍선으로 구분하고, 흰 글자가 올라가는 보라 면은 `--color-brand-dark` 로 두 테마 모두 본문 대비 4.5:1 이상(다크 5.88, 라이트 8.98).

**손대지 말 것**

- 로그인 확인은 WebSocket 연결 시 `ACCESS_TOKEN` 쿠키로 한다. 토큰이 httpOnly 라 화면 코드가 헤더로 보낼 수 없다.
- 로컬은 Valkey database 1 + 접두 `dev:`, 운영은 0 + `prod:`. Pub/Sub 채널은 DB 번호와 무관하게 공유되므로 접두를 지우면 로컬 테스트 글이 운영 방에 뜬다.
- 줄 수(5)·글자 수(200)·태그 패턴은 서버 `ChatService` 와 화면 `useChatRoom.js` 두 곳에 같은 값으로 있다. 한쪽만 바꾸면 화면은 보내지는데 서버가 거부한다.
- 키보드 대응은 CSS 변수(`--kb-inset`, `--vv-height`)로만 넘긴다. inline `bottom` 을 쓰면 카드 하단 여백이 사라진다.

**미결**

- 로그인 상태 전송·말풍선 3종·200자 빨간 카운터는 배포 후 실제 화면에서 확인 필요.
- 모바일 키보드의 줄바꿈 키도 지금은 전송으로 동작한다 — 모바일에서 줄바꿈으로 쓸지 미정.
- 한 줄일 때 입력창(약 58px)이 전송 버튼(44px)보다 높다(카운터 자리).
- 닫힐 때 애니메이션 없음. 같은 닉네임 두 명이면 둘 다 내 글로 보임.
- Valkey 가 앱보다 늦게 뜨면 Pub/Sub 구독이 재시도하지 않는다 — 앱 재시작 필요.
- 관리자 글 삭제는 API 만 있고 화면 없음.
