# 0003 광고를 자동배치가 아니라 수동 슬롯으로 심는다

## 배경

2026-08-30 Google AdSense(구글이 운영하는 광고 게재 서비스) 심사에서 **"콘텐츠 없는 화면에 광고" + "낮은 가치 콘텐츠"** 사유로 반려됐다. 원인은 자동광고(구글이 페이지를 분석해 알아서 광고를 끼워 넣는 방식)를 켜 둔 상태에서, 로딩·빈 목록·에러 화면처럼 콘텐츠가 아직 없는 자리에도 광고가 노출됐기 때문이다.

## 결정

자동광고를 끄고 **모든 광고를 수동 슬롯**으로 바꾼다.

| 항목 | 방식 |
|---|---|
| 삽입 방식 | `AdSlot.jsx` 컴포넌트를 화면 코드에 직접 배치 |
| 렌더 조건 | `!loading && !error && 데이터 ≥ 1` 일 때만 — 로딩·빈 상태·에러 화면에는 슬롯 자체를 렌더하지 않는다 |
| 배치 위치 | 첫 화면(스크롤 전) 금지, 접힌 영역(아코디언·모달·비활성 탭) 금지, 짧은 목록은 하단 1개, 긴 목록은 in-feed(중간 삽입) |
| 콘텐츠 보강 | 가이드 콘텐츠 12편 신설 — "낮은 가치 콘텐츠" 사유에 대응 |

상세 배치 규칙·슬롯 인벤토리는 `rules/fe/fe-ads.md` 로 옮겼다 — 이 결정 기록은 "왜 수동인가"만 남긴다.

## 왜 (대안과 비교)

| 대안 | 문제 | 판정 |
|---|---|---|
| 자동광고 유지, 배치 로직만 손본다 | 자동광고는 페이지 구조를 구글이 분석해 결정한다 — 코드에서 "이 화면은 콘텐츠가 없다"를 알려줄 방법이 없어 재발 확률이 높다 | 기각 |
| 수동 슬롯 + 자동광고 병행 | AdSense 콘솔의 자동광고 설정이 켜져 있으면 수동 배치 규칙이 무력화된다(수동으로 뺀 자리에도 구글이 알아서 하나 더 꽂을 수 있음) | 기각 — 자동광고는 항상 끔 유지 |
| 광고 자체를 보류하고 재심사만 미룬다 | 수익 없이 무기한 대기, 반려 사유가 구조적 문제라 시간이 지나도 안 풀림 | 기각 |

## 실제로 걸렸던 버그 — `ADS_ENABLED` 분할 게이트

2026-09-13, 표·그리드를 in-feed 광고를 위해 여러 세그먼트로 쪼개는 화면에서 광고 승인 여부(`ADS_ENABLED`)와 무관하게 "분할된 컴포넌트 인스턴스"가 항상 만들어지는 문제가 있었다. `AdSlot` 자체는 승인 전 조용히 스킵하지만, 분할 자체는 별개 동작이라 세그먼트마다 헤더 반복·컬럼 폭 계산이 달라져 광고가 안 보여도 화면이 어긋났다. 해결: `ADS_ENABLED`가 `false`일 때는 분할 자체를 하지 않고 단일 표/단일 그리드로 통짜 렌더하도록 게이트를 추가했다.

## 영향받는 곳

- `web/src/infra/ads/AdSlot.jsx` · `adConfig.js` — 슬롯 컴포넌트·스위치
- `web/index.html:39-45` — adsbygoogle 로더, 승인 전까지 주석 유지
- `rules/fe/fe-ads.md` — 배치 룰·슬롯 인벤토리·승인 전/후 상태 머신의 단일 원천

## 아직 미정인 것 (❓)

- 실제 AdSense 승인 시점 — 승인 통보 후 `ADS_ENABLED`를 `true`로 바꾸고 실 슬롯 ID를 발급받는 절차는 `rules/fe/fe-ads.md` § 5에 정리돼 있으나, 승인 자체는 이 저장소 밖의 외부 일정

확정(2026-09-30) — AdSense 승인 절차 진행은 동결한다(추가 진행 없음).
