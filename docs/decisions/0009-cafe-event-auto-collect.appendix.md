# 0009 부록 — 실측 결과

검증은 표준 라이브러리 파이썬 스크립트(저장소 밖)로 운영자 PC 에서 2026-09-30 에 돌렸다. BE 구현 시 같은 규칙을 jsoup 으로 옮긴다.

## 수집 경로

| 항목 | 결과 |
|---|---|
| 작성자별 목록 API (`CafeMemberNetworkArticleList*`) | 로그인 필요(오류 코드 0004) — 사용 불가 |
| 게시판 목록 API (`cafe-boardlist-api/v1`, `menus/1`) | 비로그인 200. 글마다 작성자 고유키·게시판 번호 포함 → GM드리미 14건 정확히 걸러짐 |
| 상세 API `cafe-articleapi/v2.1` | 비로그인 200, 본문 `contentHtml` 포함 (15건 모두). `v3` 는 500 |
| 이미지 | 우리 도메인 Referer 403 · Referer 없음 200 → 서버가 받아 S3 재업로드 |

## 이벤트 본문 (진행 중 Event 게시판 GM드리미 글 10건)

| 글 종류 | 건수 | 본문 구간 | 제목 마감 | 처리 |
|---|---|---|---|---|
| 일반 이벤트 (트로피·보름달·에픽 승급·럭키찬스 등) | 7 | **7/7 성공** — "이벤트 기간" 시작·"감사합니다" 끝 모두 발견, 이미지·보상표 보존 | 6/7 (`업데이트 이후~` 1건은 본문도 "별도 안내 시까지" → 마감 없음) | 수집 |
| 쿠폰 글 | 2 | "이벤트 기간" 문구 없음 → 추출 불가 | 1/2 | "구간 못 찾음" 초안 → 운영자가 외부 링크로 등록 |
| 모아보기 | 1 | 구간은 잡히나 이벤트 여러 개 합본 | 없음 | 제외 |

- 본문 블록 구조는 `div.se-component se-{text|image|table|horizontalLine}` 로 확인. 문단은 텍스트 블록 안 `p.se-text-paragraph` 단위라 블록이 아니라 **문단 단위**로 구간을 자른다
- 검증 스크립트(표준 라이브러리 파이썬, 저장소 밖)로 확인 — BE 구현 시 같은 규칙을 jsoup 으로 옮긴다
