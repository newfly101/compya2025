## 2. 새 시안의 정체 — 실행 가능한 앱이 아니라 "디자인 목업"

JS 자산 첫 줄에 `// GENERATED from dc-runtime/src/*.ts` 주석이 있고, 마크업에 `<x-dc>`, `<sc-if>`, `<sc-for>`, `{{ 변수 }}` 같은 템플릿 바인딩 태그가 그대로 남아있다. 이건 프레임워크 빌드 번들이 아니라 **Claude Design Canvas(.dc.html) 목업 산출물**이다 — 실제 데이터가 아니라 `{{ goalT }}`, `{{ heroWhy }}` 같은 플레이스홀더가 박혀 있고, 로직은 `<script type="text/x-dc">` 안 `class Component extends DCLogic` 하나로 들어있다(사람이 읽을 수 있는 일반 JS, 난독화 없음).

즉 **소스맵이 필요 없다** — 렌더 마크업 + 인라인 스타일 + 목업 로직 전부가 그대로 원본이다. 이 로직은 기존 `mileage-sniper.html`의 계산 로직(값 반복, E_pick 등)과 **완전히 동일**하다 — 새로 바뀐 건 화면 뿐이고 알고리즘·데이터 구조는 그대로다.

미리보기 프레임은 폭 560px·높이 900px 고정 1개뿐이다(`data-props` 안 `$preview`). 브레이크포인트 자체가 정의돼 있지 않다 — 목업이 처음부터 모바일 폭 하나로만 그려졌다는 뜻.

또한 목업에는 스테이크홀더 미리보기용 토글 2개가 딸려 있다(실제 화면엔 없던 것):

| 토글 | 옵션 | 기본값 | 의미 |
|---|---|---|---|
| `heatmap` | on/off | on | 표 셀 히트맵 음영 표시 여부 |
| `arrowStyle` | 화살표 / 글자 | 화살표 | 다음 수 표시를 ↔/↕ 기호로 할지 "구"/"연" 글자로 할지 |

→ 확정 스펙이 아니라 "이 중에 골라달라"는 열린 옵션으로 보인다. 최종 반영 전 기획 확인 필요.

## 7. 컴포넌트별 형태

- **상단 앱바**: 좌측에 22×14px 3줄 햄버거 아이콘(고정 장식, 클릭 핸들러 없음) + 가운데 정렬 제목 + 우측 빈 22px 스페이서. 기존엔 없던 구성 — 프로젝트 정책상 이 부분은 도메인이 직접 만들 게 아니라 전역 `MobileLayout` TopBar 몫으로 흡수될 자리로 보인다.
- **셀렉트**: 화살표를 `linear-gradient` 두 개로 그리는 기법은 기존과 동일하게 유지(이미지 없이 CSS만으로 셰브런 구현). 배경만 카드색이 아니라 페이지 배경색(`#100e14`)을 그대로 써서, 기존에 있던 "카드 배경≠입력창 배경(field)" 구분이 사라졌다.
- **버튼**: 주 버튼이 "꽉 찬 진한 배경"에서 "테두리 있는 옅은 틴트 배경"(보라 10~16% 알파)으로 바뀜 — 톤이 한 단계 가벼워짐.
- **추천 순서 칩**: pill 모양, 순번은 앞에 작은 숫자(투명도 0.6)로 표시하는 방식은 기존과 동일. 1등 칩과 목표 일치 칩 색만 골드→보라/호박으로 교체.
- **범례**: 항목 구성(↔/↕/●목표/▢현재) 동일, 색만 교체.
- **표 아래 캡션**: "칸을 누르면 그 자리를 지금 위치로 놓고 다음 한 수를 다시 계산합니다" — 신규 추가. 클릭 인터랙션을 몰랐던 사용자를 위한 보완 카피.
- **도움말(details/summary)**: 접고 펼치는 방식·문구 전부 기존과 동일. 화살표 회전 아이콘도 동일 기법(`border` 2개로 그린 화살표, 45˚ 회전).

## 8. 인터랙션·모션

- 버튼 hover 시 배경 톤 전환(기존엔 `transition:background .12s ease` 명시) — 새 시안 코드에는 transition 속성 자체가 없다(목업이라 정적 hover만 `style-hover`로 표기, duration 값은 없음). 실제 구현 시 기존 120ms ease 유지 권장.
- 히어로 글리프의 은은한 발광(`text-shadow`)이 새 시안엔 없음 — 의도적 제거인지 목업 생략인지 불명. 유지 여부 확인 필요.
- `prefers-reduced-motion` 대응 코드는 새 시안에 없음(목업이라 애초에 다루는 범위 밖). 이식 시 기존 규칙 유지 권장.

## 9. 반응형

새 시안은 폭 560px 고정 프레임 하나만 존재하고 별도 브레이크포인트가 없다. 프로젝트 실제 타깃 폭(모바일 360~430px)에서는:

- 버튼 2개가 가로 한 줄(`flex:1` 두 개)로 남아있는데, 이는 기존 시안이 560px 이하에서 세로로 쌓던 것과 다르다. 좁은 화면에서 버튼 글자가 눌릴 수 있어 이식 시 기존의 세로 쌓기 규칙을 유지하는 편이 안전.
- 표 레이아웃 함정은 새 시안에서도 그대로 유효: `writing-mode:vertical-rl` + `text-orientation:upright` 유지, `letter-spacing:0`(음수 금지) 유지, 행 높이 11~22px clamp 유지. **이 세 가지는 이식물에서 건드릴 필요 없음.**

- 화면 요소 구성(헤더 텍스트, 도움말, 셀렉트 3+3개, 보드/히어로/추천칩, 액션 버튼 2개, 표+범례)이 기존과 1:1 대응된다. 새로 생긴 건 표 아래 캡션 문구 한 줄 뿐이고, 이는 기존 `legend` 옆에 `<p>` 하나 추가하는 수준.
- 표는 새 시안이 div-flex로 흉내냈지만 이건 목업 툴의 한계이지 의도된 스펙이 아니다. 현재 이식물(`MileageScreen.jsx`)은 이미 시맨틱 `<table>`을 쓰고 있으므로 그대로 유지 — 바꿀 이유 없음.
- 상단 햄버거 아이콘은 도메인이 만들 부분이 아니라 전역 TopBar 영역이라 이식 대상에서 제외.

색 토큰 이관 방향(참고, 실제 반영은 후속 작업):

| 새 시안 역할 | 권장 처리 |
|---|---|
| 액센트(보라, `#6d4ad6`/`#c4b5fd`/`#dcd3ff`) | 전역 `--color-brand-dark`, `--color-brand-300`, `--color-brand`, `--color-brand-alpha-15` 계열로 대체 가능 — 새 전역 토큰 불필요 |

| 현재 위치(청록, `#5eead4`) | 일치하는 전역 토큰 없음 — 도메인 로컬 토큰 신설 필요(기존 `--color-mileage-glow` 자리에 값 추가하는 정도의 로컬 변경, 전역 토큰 신설 아님) |
