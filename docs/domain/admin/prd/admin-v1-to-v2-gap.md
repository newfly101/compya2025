## 2. 전역 요소 — v2 에 아예 없다

v1 의 모든 관리자 화면 상단에 공통으로 있었는데 v2 에는 하나도 없다. **화면을 더 그리기 전에 결정해야 한다.**

| 요소 | v1 내용 | v2 | 왜 중요한가 |
|---|---|---|---|
| **관리자 상단바** | `⚾ 컴프야펀 Admin` + 계정명(`새벽`) + **로그아웃** | ❌ 없음 | 로그아웃 경로가 사라졌다. 관리자가 세션을 끊을 방법이 없음 |
| **관리자 탭바** | `빠른 이동 · 이벤트 관리 · 쿠폰 관리 · 유저 관리` 4탭 | ❌ 없음 | v2 는 화면 간 이동이 뒤로가기뿐. 관리 화면을 오갈 때마다 홈을 거쳐야 함 |
| **모달 취소 버튼** | 모달 하단 `취소` + `등록` 2버튼 | ❌ 등록 버튼만 | 지금은 ✕ 아이콘으로만 닫을 수 있다 |

> v2 는 글로벌 `MobileLayout` TopBar 를 쓰기로 한 구조라 관리자 전용 상단바를 다시 만들지, TopBar 에 관리자용 변형을 둘지 **판단이 필요하다.**

## 4-1. 전체 대조 — Figma × 코드 (2026-08-20 병합)

`admin-code-inventory.md` 결과를 합친 것. **Figma 만 봐서는 안 보이던 것**이 드러난다.

| 기능 | v1 시안 | v2 시안 | 코드 FE | 코드 BE | 판정 |
|---|---|---|---|---|---|
| 쿠폰 관리 | ✅ | ✅ | ✅ | ✅ | 정상 |
| 이벤트 관리 | ✅ | ✅ | ✅ | ✅ | 정상 |
| 유저 관리 | ✅ | ✅ | ✅ | ✅ | 정상 |
| 공지 관리 | 메뉴만 | ✅ | ✅ | ✅ | 🟡 FE 버그 2건 |
| 스탯 영향 관리 | ❌ | ✅ | ✅ | ✅ | 정상 |
| 위키 `game-info` | ❌ | ❌ | ✅ | ❌ | 🔴 **화면은 있는데 BE 없음 → 404** |
| 대시보드 | 메뉴 | ❌ | 🟡 고아 | ❓ | 화면 파일만 있고 아무도 안 씀 |
| **퀴즈 관리** | ❌ | ❌ | ❌ | ✅ | 🔴 **BE·store 만 있고 화면이 없다** |
| **신고 관리** | ❌ | ❌ | ❌ | ✅ | 🔴 **BE 만 있다. 어느 시안에도 없음** |
| 선수카드 관리 | 메뉴 | ❌ | ❌ | ✅ | 보류 (방향 미결정) |
| 커뮤니티 4종 | 메뉴 | ❌ | 🟡 라우트 미연결 | ✅ | 후순위 |

### 새로 드러난 것 3가지

**퀴즈 관리와 신고 관리는 v1 시안에도 없었다.** BE 컨트롤러는 있는데 화면이 한 번도 그려진 적이 없다. 즉 v1→v2 이관 누락이 아니라 **처음부터 설계가 없던 기능**이다.

**위키 `game-info` 는 방향이 반대다.** 화면과 라우트는 살아 있는데 BE 엔드포인트가 없어서 열면 404 가 난다. 다른 항목들과 정반대 형태의 결함이다.

**대시보드 화면 파일은 이미 존재한다** (`AdminDashboardScreen.jsx`, 최근 커밋에 "미완" 표기). 라우터·네비게이션 어디에도 등록돼 있지 않아 아무도 도달할 수 없다.
