- **playerCard / simulate 재작업** — "로그인 전용 컨텐츠"로 방향이 이미 잡혀 있어, 재작업 시점에 유저별 결과 저장·공유 같은 참여 요소를 자연스럽게 얹을 수 있는 자리.
