### 3. admin Screen 9종 — `useAdminTopBar` 교체

각 Screen 의 기존 TopBar hook 호출을 `useAdminTopBar(title)` 로 교체. `useNavigate` import 가 onBack 용도였다면 제거 가능 (hook 내부에서 navigate 처리).

| # | 파일 | 기존 | 변경 |
|---|------|------|------|
| a | `web/src/domains/events/mobile/admin/AdminEventScreen.jsx` | `useSetTopBar({ variant:"page", title:"이벤트 관리", onBack: () => navigate(-1) })` | `useAdminTopBar("이벤트 관리")` |
| b | `web/src/domains/notices/mobile/admin/AdminNoticeScreen.jsx` | `useSetTopBar(...title:"공지 관리"...)` | `useAdminTopBar("공지 관리")` |
| c | `web/src/domains/coupons/mobile/admin/AdminCouponScreen.jsx` | `useSetTopBar(...title:"쿠폰 관리"...)` | `useAdminTopBar("쿠폰 관리")` |
| d | `web/src/domains/users/mobile/admin/AdminUserScreen.jsx` | `useSetTopBar(...title:"유저 관리"...)` | `useAdminTopBar("유저 관리")` |
| e | `web/src/domains/wiki/admin/mobile/AdminWikiScreen.jsx` | `useDomainTopBar("위키 관리")` | `useAdminTopBar("위키 관리")` |
| f | `web/src/domains/wiki/admin/mobile/AdminWikiPitchScreen.jsx` | `useDomainTopBar("마구 관리")` | `useAdminTopBar("마구 관리")` |
| g | `web/src/domains/wiki/admin/mobile/AdminWikiPitchGradeScreen.jsx` | `useDomainTopBar("구종 등급 관리")` | `useAdminTopBar("구종 등급 관리")` |
| h | `web/src/domains/wiki/admin/mobile/AdminWikiStatInfluenceScreen.jsx` | `useDomainTopBar("스탯 영향 관리")` | `useAdminTopBar("스탯 영향 관리")` |
| i | `web/src/domains/wiki/admin/mobile/AdminWikiGameInfoScreen.jsx` | `useDomainTopBar(...)` 또는 alias | `useAdminTopBar("게임 정보 관리")` |

**주의 — AdminWiki entry (e)**: 이 화면은 wiki admin 의 entry (`/admin/wiki`). back 버튼이 `/admin` (전체 대시보드) 으로 가는 게 맞음 → `useAdminTopBar` OK. 단 wiki 내부 admin sub 페이지 (f~i) back 도 `/admin` 으로 가는지, 아니면 `/admin/wiki` (wiki entry) 로 가는지는 사용자 결정 마커 — **기본값 가정: 모두 `/admin` (대시보드)**.

만약 wiki sub 들은 `/admin/wiki` 로 가는 게 더 자연스럽다면 `useAdminTopBar` 에 옵션 추가:
```js
useAdminTopBar("마구 관리", { backTo: "/admin/wiki" });
```
hook 시그니처를 `(title, options?)` 로 확장.
