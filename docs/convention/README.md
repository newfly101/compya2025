| 문서 | 내용 | 언제 보나 |
|---|---|---|
| [`frontend.md`](./frontend.md) | 프론트엔드 컨벤션 — 폴더 구조, 화면·부품 분리 기준, Redux 상태관리, 라우트 등록, 네이밍 | 화면(FE) 코드를 새로 만들거나 고칠 때 |
| [`backend.md`](./backend.md) | 백엔드 컨벤션 — 패키지 구조, 컨트롤러·서비스·매퍼 계층 규칙, 응답 형식, 권한 처리, 예외 처리 | 서버(BE) 코드를 새로 만들거나 고칠 때 |
| [`design.md`](./design.md) | 디자인 컨벤션 — 모바일 우선 원칙, 화면 폭 기준, 색상·간격·글자 크기 등 디자인 값 체계 | 화면을 디자인하거나 스타일(SCSS)을 작성할 때 |

## 참고

- Figma·MCP 관련 규칙은 이 폴더가 아니라 `docs/mcp/`에 별도로 정리된다
- 조사·감사·현황 보고서(예: 사용 안 하는 API 목록, dead code 후보 등)는 컨벤션이 아니므로 여기 포함하지 않았다 — 필요하면 `docs/global-guide/develop/specs/**` 원본을 참조
