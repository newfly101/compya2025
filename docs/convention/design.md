# 디자인 컨벤션

> 기준일: 2026-08-21
> 출처: `docs/global-guide/design/mobile-frame.md`, `docs/global-guide/develop/specs/fe/module-conventions.md`
> 대상: 모바일 전용 화면 (com2usbaseball은 PC 전용 레이아웃이 없다 — PC에서 열어도 모바일 폭 그대로 가운데 정렬해서 보여준다)

---

## 1. 모바일 우선 원칙

- 이 프로젝트는 **모바일 화면 하나만 만든다.** PC용 레이아웃을 별도로 만들지 않는다
- 화면 폭 320px ~ 480px 사이에서 자연스럽게 줄어들고 늘어나도록(fluid) 만들고, 480px을 넘어가면 더 이상 커지지 않고 가운데 정렬된 좁은 기둥 형태를 유지한다
- 320px은 반드시 지원해야 하는 최소 폭이다 (보호 대상)

| 폭 | 의미 |
|---|---|
| 320px | 지원 하한 (가장 작은 폰 화면) |
| 375px ~ 428px | 일반적인 폰 화면들 — 별도 화면을 만들지 않고 하나의 기준 화면 안에서 자연스럽게 줄어든다 |
| 480px | 기준이 되는 화면 폭 (디자인 툴에서 만드는 화면도 이 폭으로 만든다) |

---

## 2. 화면 틀(레이아웃) 표준값

| 항목 | 값 |
|---|---|
| 화면 최대 폭 | 480px, 화면보다 넓은 기기에서는 가운데 정렬 |
| 화면 좌우 여백 | 16px (기준 간격 단위 중 하나) |
| 카드 폭 | 화면 폭에서 좌우 여백을 뺀 값 (448px) |
| 상단바 높이 | 52px |
| 하단바 높이 | 56px |

320px보다 좁은 화면에서는 좌우 여백을 12px로 자동으로 줄인다.

---

## 3. 320px 미만 보호 규칙

| 규칙 | 이유 |
|---|---|
| 박스 크기 계산에 padding·border를 포함시킨다 | 여백 계산이 폭을 넘지 않게 하려고 |
| 가로 스크롤이 생기지 않게 막는다 | 좁은 화면에서 레이아웃이 깨지는 것 방지 |
| 이미지·영상은 최대 폭을 화면 폭 이하로 제한한다 | 미디어가 화면 밖으로 튀어나가지 않게 |
| 긴 단어·URL은 줄바꿈되게 한다 | 좁은 화면에서 가로로 넘치는 것 방지 |
| 한글은 단어 단위로 줄바꿈한다 | 가독성 |

금지 사항
- 고정 폭(`width: 480px`) 대신 항상 "최대 폭 + 폭 100%" 조합을 쓴다
- 긴 텍스트에 줄바꿈 금지 속성을 걸지 않는다

---

## 4. 간격 체계 (8의 배수)

| 크기 | 값 | 주 용도 |
|---|---|---|
| 최소 | 4px | 아이콘 내부, 뱃지 안쪽 여백 |
| 작음 | 8px | 섹션 구분선, 요소 사이 최소 간격 |
| 보통 | 12px | 입력창 안쪽 여백 |
| 기준 | 16px | 화면 좌우 여백 |
| 카드 | 20px | 카드 안쪽 상하 여백 |
| 섹션 간격 | 24px | 섹션과 섹션 사이 |
| 큰 간격 | 32px | 섹션 상단 여백 |
| 최대 | 48px | 페이지 맨 위 여백 |

모든 간격 값은 4의 배수로 맞추고(8의 배수를 우선), 13px·17px·21px 같은 임의의 값은 쓰지 않는다.

---

## 5. 글자 크기 (rem 단위 강제)

| 크기 | 용도 |
|---|---|
| 9px급 | 뱃지, 코드 라벨 |
| 10px급 | 아주 작은 링크 텍스트 |
| 11px급 | 캡션, 날짜 |
| 12px급 | 본문 |
| 13px급 | 강조 본문, 공지 제목 |
| 15px급 | 섹션 제목 |
| 17px급 | 상단바 로고 |
| 22px급 | 페이지 제목 |
| 28px급 | 큰 제목(히어로) |

규칙
- 글자 크기는 반드시 `rem` 또는 `em` 단위로 지정한다. `px`로 직접 쓰지 않는다 (브라우저 글자 크기 설정을 반영하기 위함, 접근성 규칙)
- 줄 간격(line-height)은 단위 없는 숫자로, 자간(letter-spacing)은 `em`으로 지정한다

---

## 6. px 단위 사용 규칙

| 화면 코드 영역 | px 직접 사용 |
|---|---|
| 화면(도메인) 코드 | 금지 — 정해진 간격/글자 크기 값만 사용. 예외: 1px 테두리, 0.5px 얇은 선, 100% 너비 |
| 공용 재사용 부품 코드 | 원칙적으로 금지, 위와 같은 예외만 허용 |
| 디자인 시스템 기초 정의 파일(변수 정의 자체) | 허용 — 원본 값을 여기서 px로 정의한다 |

이 규칙을 지키면: 폰트 확대 설정을 무시하지 않고, 320px~480px 사이에서 자연스럽게 줄어들며, 디자인 값이 임의로 흩어지지 않는다.

---

## 7. 색상 체계 (2단계)

```text
원색 값 정의 (직접 참조 금지)
       │
       ▼
의미별 이름 (배경/글자/브랜드/상태 등으로 이름 붙임)
       │
       ▼
화면 코드에서는 의미별 이름만 사용
```

- 화면 코드는 항상 의미가 담긴 색상 이름만 참조한다 (예: "기본 배경색", "본문 글자색"). 원색 값을 직접 쓰지 않는다
- 새 색상이 필요하면 원색 정의 → 의미별 이름 두 단계를 모두 추가한다
- 의미별 이름 분류: 배경(가장 아래/서브/오버레이/카드/떠있는 요소), 브랜드색(밝음~진함), 글자색(진하게/보통/흐리게/코드용), 테두리, 상태색(성공/위험/주의 — 각각 옅은 배경 버전도 있음)

---

## 8. 모서리 · 겹침 순서(레이어)

- 모서리 둥글기는 단계별 값(작음~완전 둥근 알약 모양까지)을 미리 정해두고 그 값만 사용한다. 카드는 큰 단계 값을 쓴다
- 화면 위에 뜨는 요소들(서랍 메뉴, 모달, 바텀시트, 토스트 등)은 겹침 순서 단계를 미리 정해두고 그 값만 사용한다 — 임의의 숫자를 쓰면 다른 요소와 겹칠 때 순서가 꼬인다

---

## 9. 탭 대상 크기 (터치 접근성)

| 기준 | 최소 크기 |
|---|---|
| 이 프로젝트 채택 값 | 44 × 44px |

- 아이콘 자체는 작아도, 눌렀을 때 반응하는 영역은 안쪽 여백을 더해서 44px을 확보한다 (보이는 크기 ≠ 누르는 영역)
- 인접한 버튼 사이는 최소 8px 간격을 둔다

---

## 10. 화면 골격 표준

- 화면 전체는 상단바 + 서랍 메뉴 + 스크롤되는 본문, 이 세 부분을 묶은 틀 하나만 쓴다. 화면마다 새로 만들지 않는다
- 상단바는 세 가지 모양만 존재한다: 기본형(로고+메뉴버튼+로그인), 뒤로가기형(제목+뒤로가기), 메뉴버튼형(제목+메뉴버튼)
- 화면(도메인)마다 별도의 헤더를 새로 만들지 않는다

---

## 11. 이미 만들어진 재사용 부품

| 부품 | 용도 |
|---|---|
| 라벨/고정/상태 뱃지 3종 | 목록이나 카드 위에 상태를 표시 |
| 섹션 틀(제목+본문 묶음) | 화면을 섹션 단위로 나눌 때 |
| 켜고끄기 스위치 | 공개 여부 등 on/off 값 표시·수정 |
| 알림 모달 | 안내 문구 표시 (용도 고정, 범용 모달 아님) |

새 화면을 만들 때는 위 부품이 있는지 먼저 확인하고, 없는 부품(버튼/입력창/범용 모달/바텀시트 등)은 화면마다 따로 만들지 말고 공용 부품으로 새로 만들 것을 검토한다.

---

## 12. 화면 제작 체크리스트

- [ ] 기준 화면 폭 480px로 만든다
- [ ] 화면 좌우 여백 16px
- [ ] 모든 간격은 정해진 간격 값만 사용 (4의 배수)
- [ ] 글자 크기는 rem 단위(정해진 값) 사용, px 직접 사용 금지
- [ ] 색상은 의미별 이름으로만 사용, 원색 직접 참조 금지
- [ ] 이미지/미디어는 최대 폭 100% 제한
- [ ] 한글은 단어 단위 줄바꿈, 긴 URL은 줄바꿈 처리
- [ ] 탭 대상 44px 이상 확보
- [ ] 가로 스크롤 생기지 않게 처리
- [ ] 320px 미만에서도 깨지지 않는지 확인

---

## 13. 자주 하는 실수

| 실수 | 문제 | 해결 |
|---|---|---|
| 화면 폭을 여러 기준으로 따로 만듦 (375/390/414/480 혼용) | 코드로 옮길 때 비율이 깨짐 | 480 하나로 통일 |
| `width: 480px` 같은 고정값 사용 | 320px 화면에서 가로 스크롤 발생 | 최대 폭 + 폭 100% 조합 사용 |
| 글자 크기를 px로 직접 지정 | 사용자 글자 확대 설정 무시, 접근성 위반 | rem 단위 정해진 값 사용 |
| 간격을 13px, 17px 같은 임의 값으로 지정 | 간격 체계가 어긋남 | 정해진 간격 값만 사용 |
| 탭 영역이 32px처럼 작음 | 터치 오조작 증가 | 안쪽 여백으로 44px 확보 |
| 긴 한글에 줄바꿈 금지 속성 사용 | 가로로 넘침 | 단어 단위 줄바꿈 처리 |
| 모달 폭을 320px 고정 + 좌우 여백 0으로 만듦 | 가장 작은 화면에서 여백이 없어짐 | 화면 폭에서 여백을 뺀 값으로 계산 |
