# OPS-04 테스트 공백

> 상태: 열림
> 심각도: 🟠 이관 중 해결
> 닫히는 단계: 0~1단계 — [`phase-0`](../../03-roadmap/phase-0-baseline.md), [`phase-1`](../../03-roadmap/phase-1-blockers.md)
> 관련: OPS-02

## 현상
이관은 "같은 화면을 다른 기술로 다시 만드는 일" 이라 **전후가 같은지 확인하는 수단**이 핵심이다. 지금은 그 수단이 거의 없다.

## 근거
| 영역 | 현황 |
|---|---|
| BE | `src/test` 5파일 · `@Test` 27개. `contextLoads` 1, 매퍼 테스트 17(**실제 DB 필요**), 분석 이벤트 단위 테스트 9 |
| BE 없는 것 | 컨트롤러 · 보안 필터 · 인증 흐름 · 예외 매핑 테스트 0 |
| FE | 테스트 러너 없음. 검증은 `verify-prerender.mjs`(파일 존재 · 크기)뿐 |
| CI | 어느 워크플로도 테스트를 실행하지 않음([OPS-02](./OPS-02-deploy-pipeline.md)) |

## 영향
- 1단계 BE 수정(필터 · 예외 · OAuth)은 **보안 경계**를 건드린다. 테스트 없이 바꾸면 "로그인은 되는데 관리자 API 가 열렸다" 같은 회귀를 못 잡는다.
- 4단계에서 페이지를 옮길 때 기존 페이지와 **같은 내용 · 같은 메타**인지 사람이 눈으로 비교해야 한다.

## 해결 방향
| 대상 | 테스트 | 도입 단계 |
|---|---|---|
| BE 예외 매핑 · 보안 규칙 | `@WebMvcTest` + `spring-security-test` — 공개/인증/관리자 경로 × 토큰 없음/유효/만료/위조 | 1 |
| BE OAuth state | 서비스 단위 테스트 | 1 |
| BE 매퍼 | Testcontainers MariaDB 로 실제 DB 의존 제거 | 선택 |
| **FE 이관 동등성** | Playwright(설치된 Chromium 재사용)로 **기준선 스크립트**: 공개 경로 목록을 돌며 `title` · description · canonical · `h1` · 주요 목록 항목 수를 JSON 으로 저장. 0단계에서 현행 사이트 기준선을 찍고, 이관된 페이지와 비교 | 0 (기준선), 4~6 (비교) |
| FE 컴포넌트 | 도입하지 않음(이 규모에선 동등성 테스트가 비용 대비 효과 큼) | — |

## 완료 기준

- [ ] 보안 규칙 테스트가 `/api/admin/**` 비인가 접근 403 을 확인한다
