## 3. 결함 md 템플릿

```markdown
# {ID} {제목}

> 상태: 열림 | 진행 | 확인 | 닫힘
> 심각도: 🔴 이관 차단 | 🟠 이관 중 해결 | 🟡 정리
> 닫히는 단계: {n}단계 — ../../03-roadmap/phase-{n}-*.md
> 관련: {다른 ID}

## 현상
사용자 · 크롤러 · 운영자가 겪는 일을 한두 문장으로.

## 근거
| 위치 | 내용 |
|---|---|
| `파일:줄` | 무엇이 그렇게 되어 있나 |

## 영향
지금 무엇이 깨지나 / 이관하면 무엇이 깨지나.

## 해결 방향
무엇을 바꾸나. 대안이 있으면 표로.

## 완료 기준
- [ ] 확인 가능한 문장으로 (명령 · 화면 · 응답 코드)
```
