# data_history_roster 포지션 매칭 리포트

자동 생성 파일 (scripts/gen_history_roster_position.py). 직접 고치지 말 것.

## 요약

매칭을 3단계로 강화했다 — 1순위 (이름,구단,연도), 2순위 (이름,연도) 폴백,
3순위 접미(B/S/C) 정규화. 구단은 로스터 행에 없지만
data_history_round.round_label('83 삼미' 등)을 파싱해 역추적했다.

| 구분 | 건수 |
|---|---|
| 전체 로스터 행 | 1750 |
| 확정 — 1순위 구단키 (이름,구단,연도) | 1612 |
| 확정 — 2순위 구단폴백 (이름,연도) | 123 |
| 확정 — 3순위 접미정규화 | 9 |
| **확정 합계 (UPDATE 생성)** | **1744** |
| 모호 (포지션 2개 이상) | 1 |
| 미매칭 (엑셀에 이름 자체가 없음) | 5 |

**구단키 도입 효과** — (이름,연도) 2키만 썼을 때 모호 1건 → 구단키(1순위) 도입 후 모호 1건.

**접미정규화 도입 효과** — 1·2순위까지만 썼을 때 미매칭 14건 → 3순위(접미정규화) 도입 후 미매칭 5건 (9건 감소).
